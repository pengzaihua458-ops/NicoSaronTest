## Core Principles

- **Security First**: We prioritize atomic, high-impact security changes to protect our users and infrastructure.
- **Accessibility is Not Optional**: We strive to make our interfaces usable for everyone, regardless of their ability.
- **UX Excellence**: Every interaction should feel smooth, intuitive, and pleasant.
