# Nico Saron Test

Welcome to the Nico Saron Test project. This repository is dedicated to maintaining high standards of security, accessibility, and user experience.

## ⚡ Quick Links

- 🛡️ [Security Policy](./SECURITY.md) - How to report vulnerabilities.
- 📓 [Sentinel Journal](./.jules/sentinel.md) - Security hardening records.
- 🎨 [Palette Journal](./.jules/palette.md) - UX and accessibility improvements.

## 🎯 Core Principles

- **Security First**: Protecting user data and maintaining system integrity is our top priority.
- **Accessibility is Not Optional**: We strive to make our interface usable for everyone, regardless of their abilities.
- **UX Excellence**: Every interaction should be intuitive, pleasant, and efficient.
