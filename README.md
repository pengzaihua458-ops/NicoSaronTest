# Performance Foundation

A foundational repository for performance-focused projects, emphasizing security and best practices.

## 🛡️ Security First

This project enforces a secure-by-default environment:
- **Node.js Enforcement:** Requires Node.js >=20.0.0 for modern security features.
- **Supply Chain Hardening:** Blocks unauthorized build scripts via `pnpm.onlyBuiltDependencies`.
- **Security Auditing:** Automated auditing with a `high` threshold.
