# nicosarontest

Welcome to the foundational repository for security and documentation best practices.

## Getting Started

This project uses `pnpm` for package management and `prettier` for code formatting.

### Available Scripts

- `pnpm lint`: Checks the codebase for formatting issues (optimized with caching).
- `pnpm format`: Automatically formats the codebase (optimized with caching).
- `pnpm audit`: Runs a security audit of dependencies.
- `pnpm test`: Placeholder for future tests.
