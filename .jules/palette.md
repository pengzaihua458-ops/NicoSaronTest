# Palette Journal

## 2026-06-11 - [Separating UX from Policy]

**Learning:** Enhancing documentation as an interface (e.g., adding interactive mailto templates) is a valid UX win, but it must be strictly decoupled from modifying the underlying business or security policies (like SLAs or support matrices) which are outside Palette's scope.
**Action:** When improving documentation UX, only touch the presentation/interaction layer and avoid introducing new commitments or policy changes.
