# Palette Journal

## 2026-08-16 - [Vulnerability Reporting UX Enhancement]

**Learning:** In documentation-heavy or repository-only projects lacking web application UI components, interaction friction can be significantly reduced by providing structured pre-filled `mailto:` links and explicit copy-paste template blocks in `SECURITY.md`.
**Action:** Always include both direct pre-formatted mailto links and plaintext copy-paste report templates in vulnerability reporting documentation to accommodate all user email clients and workflows.
