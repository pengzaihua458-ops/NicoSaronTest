## 2026-08-16 - Structured Vulnerability Report Template UX

**Learning:** In documentation-centric or minimal repositories without custom UI components, providing pre-formatted `mailto:` links with pre-filled subject/body parameters along with a copy-paste template block significantly reduces cognitive load and friction for security reporters.
**Action:** Enhance standard security reporting docs with pre-structured email templates and copy-paste fallback blocks.
