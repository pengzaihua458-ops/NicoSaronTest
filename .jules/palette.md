# Palette Journal

## 2026-03-21 - [Structured Documentation-as-UI]

**Learning:** In documentation-heavy foundational repositories, treating `README.md` and `SECURITY.md` as functional UIs—using structured sections, emojis for scannability, and interactive `mailto:` templates—significantly reduces cognitive load and accelerates user actions like vulnerability reporting.
**Action:** Always provide "Quick Links" in `README.md` and use interactive, structured templates for non-code interactions (e.g., security reporting).
