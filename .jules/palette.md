# Palette Journal

## 2026-08-12 - [Reducing Interaction Cost in Empty Repositories]

**Learning:** In documentation-only or empty repositories, users encounter significant friction when trying to report security vulnerabilities manually. Providing an automated mailto link with a pre-filled subject and template body, accompanied by a copy-paste fallback block, reduces interaction cost and ensures a smoother, more accessible user experience.
**Action:** For documentation-only repos, proactively implement structured mailto links and fallback copy templates to make reporting effortless and intuitive.
