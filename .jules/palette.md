# Palette Journal

## 2026-08-31 - Reducing Interaction Cost in Security Reporting

**Learning:** In repositories without interactive application UI or frontend components, security documentation like `SECURITY.md` is the primary human-facing interface. Standard email links require reporters to manually format subject lines and body structures, introducing unnecessary friction and cognitive load.
**Action:** Provide pre-filled `mailto:` links with subject and template body parameters alongside a copy-paste fallback block to minimize interaction cost and streamline vulnerability reporting.
