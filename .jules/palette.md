# Palette Journal

## Philosophy
- Users notice the little things
- Accessibility is not optional
- Every interaction should feel smooth
- Good UX is invisible - it just works

## 2026-07-08 - Reducing friction in security reporting
**Learning:** In documentation-only repositories, UX is primarily a function of information architecture. Reducing friction for critical tasks like security reporting via pre-filled templates is a major micro-UX win.
**Action:** Always consider structured mailto links or pre-filled issue templates to guide users.
