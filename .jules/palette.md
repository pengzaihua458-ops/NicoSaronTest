# Palette Journal

## 2026-02-22 - [Vulnerability Reporting UX Improvement]
**Learning:** In documentation-heavy repositories, usability is driven by structured information. Providing a dual-path reporting flow (pre-filled `mailto` and fallback template) ensures that security researchers can report issues efficiently regardless of their local environment or email client capabilities.
**Action:** Standardize the use of pre-filled links and fallback templates for critical documentation workflows to improve accessibility and user success rates.
