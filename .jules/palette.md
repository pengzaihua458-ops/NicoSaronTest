## 2026-04-02 - [Documentation UX Foundations]
**Learning:** In sparse repositories, a non-circular documentation navigation system (where the current page is omitted from the menu) and pre-filled mailto templates significantly reduce contributor cognitive load and improve reporting efficiency.
**Action:** Always implement relative-path navigation bars and structured templates for critical communication channels like security reporting.
