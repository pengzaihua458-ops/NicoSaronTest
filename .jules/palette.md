# Palette Journal

## 2026-08-16 - Streamline Security Report Creation in Documentation Repositories

**Learning:** In repositories without interactive UI components, security reporting UX can be significantly improved by reducing interaction cost. Providing pre-filled mailto parameters alongside an explicit copy-paste template block ensures seamless reporting regardless of user email client capabilities.
**Action:** Always include both structured mailto links (subject & body) and a plain-text template fallback block when refining vulnerability reporting instructions in `SECURITY.md`.
