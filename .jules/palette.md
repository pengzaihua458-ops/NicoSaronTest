# Palette Journal

## 2026-02-08 - [Reducing Interaction Cost]

**Learning:** In documentation-only repositories lacking interactive web components, vulnerability reporting via `SECURITY.md` is the primary interactive user flow, where friction can be minimized by providing pre-composed mailto links and explicit template fallbacks to reduce cognitive load and interaction cost.
**Action:** Enhance security report links with structured query parameters (subject and body templates) to pre-fill emails, and offer copy-pasteable blocks as accessible fallback options.
