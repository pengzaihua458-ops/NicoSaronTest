## 2025-02-25 - Documentation as UI
**Learning:** In repositories without a graphical user interface, documentation (README.md, SECURITY.md) acts as the primary user interface. UX improvements in this context should focus on streamlining information flow, using structured templates, and providing interactive elements like pre-filled `mailto` links to reduce user friction.
**Action:** When working on documentation-only repositories, treat every Markdown file as a UI component and look for ways to make it more actionable and scannable.
