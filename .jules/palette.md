# Palette Journal

## 2026-03-13 - [Documentation UX and Discoverability]

**Learning:** Documentation files are the primary 'interface' for repository users. Applying UX principles like "Quick Links" with descriptive emojis and providing structured reporting templates in `SECURITY.md` significantly reduces friction and improves the overall developer experience.
**Action:** Always include a "Quick Links" section in root READMEs and use URL-encoded `mailto:` templates to guide user input for reporting or support.
