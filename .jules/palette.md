# Palette Journal

## 2026-07-26 - Reducing Interaction Cost in Documentation-Only Repositories

**Learning:** In documentation-centric environments lacking interactive user interfaces, the "User Interface" is the documentation itself. High interaction cost occurs when users are required to manually copy, paste, and structure their inputs. By providing pre-filled, context-aware action links (such as mailto links with structured body templates) alongside explicit copy-paste fallbacks, we can significantly lower cognitive load and reporting friction.
**Action:** Always provide structured mailto links with pre-filled subject and template body parameters when designing security contact info, accompanied by visual markdown template blocks as copy-paste fallbacks.
