# Palette Journal

## 2026-02-13 - [Documentation as UI]

**Learning:** In repositories lacking a graphical user interface, documentation (README.md, SECURITY.md) acts as the primary user interface. Streamlining information flow and providing interactive elements like pre-filled mailto links (requiring URL-encoding for characters like '#') significantly improves the researcher experience.
**Action:** Always ensure documentation is clear, well-formatted, and includes interactive shortcuts for common tasks like reporting vulnerabilities.
