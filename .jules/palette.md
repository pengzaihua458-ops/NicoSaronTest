# Palette Journal

## 2026-02-21 - [Interactive Documentation as UI]
**Learning:** In documentation-only repositories, the documentation *is* the user interface. Micro-UX improvements like pre-filled `mailto:` links and structured reporting templates significantly reduce friction for specialized users (e.g., security researchers), turning a static policy into an interactive workflow.
**Action:** Always provide interactive shortcuts alongside structured fallbacks in documentation-heavy foundations to cater to different user environments and preferences.
