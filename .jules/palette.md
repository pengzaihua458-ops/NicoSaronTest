# Palette's Journal

## 2026-02-08 - Reducing Interaction Cost in Security Reporting
**Learning:** In documentation-only repositories, UX is primarily a function of information architecture. By providing structured mailto links and clear copy-paste templates, we dramatically lower the interaction cost for researchers reporting vulnerabilities.
**Action:** When building security reporting documents, always supply a structured mailto link with pre-filled template parameters, accompanied by an explicit copy-paste fallback block to avoid breaking on client-side mail handlers.
