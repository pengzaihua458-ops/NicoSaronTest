# Palette Journal

## 2026-07-19 - Reducing Interaction Cost in Documentation-only Repositories

**Learning:** In a repository containing only documentation and no active codebase, UX enhancements are centered on the information architecture and reducing friction. Pre-filling a structured vulnerability report template via a `mailto:` link reduces the user's interaction cost, guiding them to submit high-quality, actionable reports on the first attempt without requiring manual template copying.
**Action:** Always provide structured mailto links with pre-filled templates in SECURITY.md for documentation-centric projects to ensure seamless, accessible reporting flows.
