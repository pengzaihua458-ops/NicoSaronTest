# Palette Journal

## 2026-08-16 - [Vulnerability Reporting UX]

**Learning:** In documentation-centric or minimal repositories, vulnerability reporting UX can be significantly improved by converting plain mailto links into structured mailto URLs with pre-filled subject and body parameters, coupled with a copy-paste fallback block for webmail users.
**Action:** Always provide structured mailto links with subject/body parameters along with explicit markdown code blocks for manual copy-paste reporting.
