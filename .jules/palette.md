## 2026-03-21 - [Structured Documentation Navigation]

**Learning:** Structured 'Quick Links' and a persistent navigation bar in documentation act as a functional UI, significantly reducing cognitive load and improving orientation for new contributors in sparse repositories.
**Action:** Always provide a 'Quick Links' section with descriptive emojis and a consistent navigation bar across all core documentation files.

## 2026-03-21 - [Streamlined Security Reporting UX]

**Learning:** Providing a pre-filled `mailto:` link with a structured template (Subject and Body) in `SECURITY.md` reduces reporter friction and ensures that critical information is captured immediately during the initial report.
**Action:** Use URL-encoded `mailto:` templates for security reporting to guide users through the disclosure process and improve triage efficiency.
