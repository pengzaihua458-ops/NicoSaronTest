## 2026-08-15 - Streamlining Vulnerability Reporting UX

**Learning:** In repositories with limited code or documentation-centric setups, reducing friction for security reporters by pre-filling report templates via structured mailto links and providing plain text fallback blocks significantly improves reporting UX and submission quality.
**Action:** When updating security documentation, provide both a structured `mailto:` link with pre-filled subject/body parameters and a formatted copy-paste fallback block for email clients that do not support complex mailto query parameters.
