# Palette's Journal

## 2026-08-16 - Reducing Vulnerability Reporting Friction in Minimal Repositories

**Learning:** In repositories without interactive UI components, security reporting documentation is the primary interface users interact with. Providing structured `mailto:` action links alongside explicit fallback copy-paste blocks significantly reduces user cognitive load and input effort.
**Action:** Always complement `mailto:` reporting links with structured templates and copy-paste fallback code blocks.
