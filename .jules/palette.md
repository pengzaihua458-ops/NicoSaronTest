# Palette UX Journal

## 2026-08-16 - Pre-filled mailto and fallback copy-paste templates reduce vulnerability reporting friction

**Learning:** In documentation-centric or empty repositories without interactive UI components, security reporting UX is often hindered by plain `mailto:` links requiring reporters to compose vulnerability details from scratch.
**Action:** Provide pre-formatted `mailto:` links with `subject` and `body` parameters alongside a copy-paste Markdown fallback template block to minimize interaction cost and cognitive load for security researchers.
