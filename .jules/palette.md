# Palette Journal

## 2026-02-08 - [Vulnerability Reporting UX]

**Learning:** In documentation-only repositories, reducing interaction cost is paramount. Users are more likely to report vulnerabilities when provided with a structured, pre-filled `mailto` link that simplifies the reporting process. Combining this link with a clear copy-paste fallback ensures high accessibility across different mail clients.
**Action:** Always provide a structured `mailto` link featuring pre-filled subject and template body parameters, paired with a manual copy-paste fallback to accommodate all user setups.
