# Palette Journal

## 2026-03-02 - [Enhance security reporting usability]
**Learning:** In projects without a graphical user interface, documentation like `SECURITY.md` acts as the primary user interface. UX improvements here should focus on reducing friction in information flow, such as using pre-filled templates and clear fallbacks for different user environments.
**Action:** Always provide both a pre-filled `mailto` link and a structured Markdown template in security reporting documentation to ensure the best possible reporting experience.
