## 2026-08-21 - [Reducing Interaction Cost in Security Reporting]

**Learning:** In documentation-only repositories lacking interactive web components, vulnerability reporting UX can be significantly improved by reducing interaction friction and cognitive load through pre-filled structured `mailto:` parameters and explicit copy-paste template blocks.
**Action:** When updating security reporting documentation, always provide both a direct `mailto:` link with pre-populated subject/body query parameters and a formatted plain-text code block fallback for email clients that do not parse URL query parameters.
