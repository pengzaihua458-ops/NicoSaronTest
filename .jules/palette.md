# Palette Journal

## 2026-08-22 - [Vulnerability Reporting UX]

**Learning:** In documentation-centric or minimal repositories, security reporting experience suffers if reporters must manually compose emails without guidance on required details.
**Action:** Provide structured `mailto:` links with pre-filled subject and template body parameters alongside copy-paste fallback code blocks.
