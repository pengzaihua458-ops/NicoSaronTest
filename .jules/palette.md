# Palette Journal

## 2026-07-31 - [Vulnerability Reporting UX Enhancement]

**Learning:** In documentation-only/empty repositories, security reporting instructions represent the primary user interface. Reducing interaction cost via a pre-filled, structured mailto link improves the security reporting workflow significantly, while keeping a copy-paste fallback template ensures full accessibility for systems without mailto protocol handlers.
**Action:** Always provide both a quick mailto generator and a clean markdown/text fallback template to accommodate different devices, mail clients, and user environments.
