# Palette Journal

## 2026-08-10 - [Reducing Interaction Cost in Empty Repositories]

**Learning:** In documentation-only or empty repositories, users reporting security vulnerabilities face high friction if they have to manually construct report emails. Providing a structured mailto link along with a clear copy-paste fallback template directly in SECURITY.md significantly reduces the interaction cost and improves the report quality.
**Action:** Always enhance SECURITY.md with pre-filled mailto parameters and a copy-paste fallback block to streamline the vulnerability reporting UX.
