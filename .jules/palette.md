# Palette Journal

## 2026-08-04 - [Vulnerability Reporting UX]

**Learning:** In documentation-only or empty repositories, the core user interaction point is typically the documentation itself (e.g., security policies). Enhancing reporting protocols with pre-filled communication templates significantly reduces friction and error rates for external researchers.
**Action:** When working with documentation-centric projects, look for opportunities to streamline contact/reporting mechanisms with pre-filled templates and robust fallbacks.
