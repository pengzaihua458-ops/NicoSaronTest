# Palette Journal

## 2026-07-28 - [Vulnerability Reporting UX Enhancement]

**Learning:** In documentation-only repositories, vulnerability reporting UX can be significantly improved by replacing flat text guidelines with a pre-filled, structured `mailto` link that maps report structures directly, while maintaining a clear, copy-pasteable fallback text block to guarantee accessibility across all mail user agents.
**Action:** Always provide both structured pre-filled links and explicit fallback templates when configuring markdown-based vulnerability reporting mechanisms.
