## 2026-08-31 - Vulnerability Reporting Interaction Friction

**Learning:** In repositories with minimal code or documentation focus, security reporters experience friction when drafting reports from scratch. Pre-filling mailto link parameters and providing a standardized copy-paste report block drastically improves report quality and speed.
**Action:** Always include pre-filled mailto query parameters (subject and body outline) along with a fallback text block in `SECURITY.md`.
