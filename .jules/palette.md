## 2026-08-14 - Frictionless Vulnerability Reporting in Documentation-Centric Repositories

**Learning:** In repositories containing only documentation and security baselines, user experience improvements center on documentation usability and interaction cost. Adding structured mailto links with pre-filled subject/body parameters along with copy-paste fallback templates reduces reporting friction and improves reporter clarity.
**Action:** When updating security documentation, provide pre-filled mailto links alongside structured copy-paste markdown templates to accommodate both native mail clients and webmail users.
