## 2026-08-04 - [Reducing Interaction Cost in Documentation-Only Repositories]

**Learning:** In empty or documentation-only repositories lacking standard UI components, the key UX surface is the documentation itself (e.g., `SECURITY.md`). We can drastically reduce the cognitive load and interaction cost of reporting security vulnerabilities by providing a pre-configured `mailto` link alongside a clear, well-structured fallback copy-paste block.
**Action:** Always provide both a one-click `mailto` link with pre-filled subject and body templates, and a visual copy-paste markdown fallback for users whose system email clients are not configured.
