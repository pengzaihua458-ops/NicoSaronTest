## 2026-08-01 - [Reducing Interaction Cost in Empty Repositories]

**Learning:** In repositories containing only documentation or no application code, we can significantly reduce user interaction and friction by providing structured, pre-filled report pathways (such as structured mailto links and ready-to-copy report templates).
**Action:** When updating or creating `SECURITY.md`, always include both an interactive `mailto` link containing pre-filled subject/body parameters and an explicit markdown fallback block to guarantee high-fidelity reports.
