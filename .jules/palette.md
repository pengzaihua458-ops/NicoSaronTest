# Palette Journal

## 2026-03-05 - [Streamlining Security Reporting]
**Learning:** Documentation serves as a primary user interface for developers and security researchers. Reducing friction in the reporting flow by using pre-filled `mailto:` links and structured Markdown templates significantly improves the UX of responsible disclosure.
**Action:** Always provide both a pre-filled `mailto:` link and a copy-pasteable Markdown template in `SECURITY.md` to accommodate different user environments.
