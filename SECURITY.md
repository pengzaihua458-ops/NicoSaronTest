# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via email:
   - **Recommended:** Click to [Draft a Structured Security Report](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BBrief%20Description%5D&body=I%20would%20like%20to%20report%20a%20potential%20security%20vulnerability.%0A%0A%23%23%23%20%F0%9F%93%8B%20Vulnerability%20Details%0A-%20%2A%2AType/Component%2A%2A%3A%20%5Be.g.%2C%20Auth%2C%20API%2C%20Dependency%5D%0A-%20%2A%2ASeverity%2A%2A%3A%20%5BLow%20/%20Medium%20/%20High%20/%20Critical%5D%0A%0A%23%23%23%20%F0%9F%94%8D%20Description%0A%5BDescribe%20the%20vulnerability%20and%20its%20potential%20impact%20here%5D%0A%0A%23%23%23%20%F0%9F%9B%A0%EF%B8%8F%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%23%20%F0%9F%8E%AF%20Expected%20Behavior%20vs%20Actual%20Behavior%0A-%20%2A%2AExpected%2A%2A%3A%20%5BWhat%20should%20happen%5D%0A-%20%2A%2AActual%2A%2A%3A%20%5BWhat%20actually%20happens%5D%0A%0A%23%23%23%20%F0%9F%A9%B9%20Suggested%20Remediation%20%28Optional%29%0A%5BAny%20suggestions%20for%20how%20to%20fix%20the%20issue%5D) to launch your default email client with a pre-filled, structured template.
   - **Alternative:** Send an email to [security@example.com](mailto:security@example.com) with the following markdown template:

   ```markdown
   ### 📋 Vulnerability Details

   - **Type/Component**: [e.g., Auth, API, Dependency]
   - **Severity**: [Low / Medium / High / Critical]

   ### 🔍 Description

   [Describe the vulnerability and its potential impact here]

   ### 🛠️ Steps to Reproduce

   1. [Step 1]
   2. [Step 2]

   ### 🎯 Expected Behavior vs Actual Behavior

   - **Expected**: [What should happen]
   - **Actual**: [What actually happens]

   ### 🩹 Suggested Remediation (Optional)

   [Any suggestions for how to fix the issue]
   ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
