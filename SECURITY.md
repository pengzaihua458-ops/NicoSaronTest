# Security Policy

## Supported Versions

The following versions are currently supported for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it via the official [GitHub Security Advisory channel](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new).

Alternatively, you can email your findings to [security@example.com](<mailto:security@example.com?subject=Vulnerability%20Report&body=Please%20provide%20a%20detailed%20description%20of%20the%20vulnerability%2C%20including%20steps%20to%20reproduce%2C%20affected%20component(s)%2C%20and%20potential%20impact.>).

### Reporting Template

When reporting a vulnerability, please include the following information:

- **Vulnerability Type:** (e.g., XSS, SQL Injection)
- **Severity:** (Critical, High, Medium, Low)
- **Affected Component(s):**
- **Description:** A clear and concise description of the vulnerability.
- **Steps to Reproduce:**
- **Proof of Concept:** (If applicable)
- **Impact:** What could happen if this is exploited?
- **Suggested Mitigation:** (If known)

## Response Timeline

- **Acknowledgment:** Within 48 hours.
- **Initial Assessment:** Within 7 business days.

Thank you for helping keep this project secure!
