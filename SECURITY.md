# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions:

| Version | Supported |
| ------- | --------- |
| v1.x    | ✅ Yes    |
| < v1.0  | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [Report a vulnerability via email](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Type%20of%20Vulnerability%3A%20%0A-%20Severity%3A%20%0A-%20Description%3A%20%0A-%20Steps%20to%20Reproduce%3A%20%0A-%20Impact%3A%20)
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy, fill out, and email the template below to [security@example.com](mailto:security@example.com):

```text
Type of Vulnerability: [e.g. XSS, SQL Injection]
Severity: [Low/Medium/High/Critical]
Description: [Provide details about the issue]
Steps to Reproduce: [Include code snippets, URLs, payloads, etc.]
Impact: [What could happen if exploited]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
