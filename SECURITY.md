# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=%23%23%20Vulnerability%20Details%0A-%20Type%3A%20%5Be.g.%2C%20XSS%2C%20SQLi%2C%20Auth%20Bypass%5D%0A-%20Severity%3A%20%5BCritical%2FHigh%2FMedium%2FLow%5D%0A%0A%23%23%20Description%0A%5BDescribe%20the%20vulnerability%20here%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%0A2.%20%0A3.%20%0A%0A%23%23%20Impact%0A%5BWhat%20can%20an%20attacker%20do%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
