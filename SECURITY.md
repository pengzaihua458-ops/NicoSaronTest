# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=---%0Atype%3A%20%3Ctype%20of%20vulnerability%3E%0Aseverity%3A%20%3Ccritical%7Chigh%7Cmedium%7Clow%3E%0A---%0A%0A%23%23%20Description%0A%3Cbriefly%20describe%20the%20issue%3E%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%3Cstep%20one%3E%0A2.%20%3Cstep%20two%3E%0A%0A%23%23%20Impact%0A%3Cwhat%20can%20an%20attacker%20do%3F%3E).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
