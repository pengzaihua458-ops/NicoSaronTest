# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via our [Security Vulnerability Report Template](<mailto:security@example.com?subject=%F0%9F%9A%A8%20Security%20Vulnerability%20Report&body=###%20Vulnerability%20Details%0A-%20**Type:**%20(e.g.%20XSS,%20SQLi,%20Auth%20Bypass)%0A-%20**Severity:**%20(Critical/High/Medium/Low)%0A%0A###%20Description%0A(Provide%20a%20detailed%20description%20of%20the%20vulnerability)%0A%0A###%20Steps%20to%20Reproduce%0A1.%20(Step%20one)%0A2.%20(Step%20two)%0A%0A###%20Impact%0A(What%20could%20happen%20if%20exploited?)>).
3. Alternatively, email your findings directly to [security@example.com](mailto:security@example.com).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
