# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings directly using our [pre-filled report email template](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. Alternatively, copy and send the template below to `security@example.com`:

```text
Subject: [SECURITY] Vulnerability Report

Description:
[Provide a clear description of the vulnerability]

Steps to Reproduce:
1.
2.
3.

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
