# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Main    | ✅ Yes     |
| < 1.0.0 | ❌ No      |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us.

**Do not** open a public issue.

### 🛡️ [Report a Security Vulnerability](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%5D%0ASeverity%3A%20%5BCritical%2FHigh%2FMedium%2FLow%5D%0ADescription%3A%20%5BDescription%20of%20the%20vulnerability%5D%0ASteps%20to%20Reproduce%3A%20%5BSteps%5D%0AImpact%3A%20%5BExpected%20impact%5D)

Alternatively, you can email your findings to [security@example.com](mailto:security@example.com) with the following details:

1. **Type of vulnerability**
2. **Severity**
3. **Detailed description**
4. **Steps to reproduce**
5. **Expected impact**

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
