# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us using one of the following channels:

### 1. GitHub Security Advisory (Preferred)

The most secure way to report a vulnerability is through the [GitHub Security Advisory](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) interface. This keeps the conversation private and allows us to collaborate on a fix securely.

### 2. Email (Fallback)

If you are unable to use the GitHub interface, you can email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AExpected%20Behavior%3A%0A%0AActual%20Behavior%3A%0A%0AImpact%3A).

Please include:

- A detailed description of the vulnerability.
- Step-by-step instructions to reproduce the issue.
- Potential impact of the vulnerability.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
