# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=**Vulnerability%20Details**%0A-%20Type%3A%20%5BType%2C%20e.g.%2C%20XSS%2C%20SQLi%5D%0A-%20Severity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0A**Description**%0A%5BDescribe%20the%20vulnerability%5D%0A%0A**Steps%20to%20Reproduce**%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A**Impact**%0A%5BWhat%20can%20happen%20if%20exploited%5D).
3. Provide a detailed description of the vulnerability using the template provided in the link above.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
