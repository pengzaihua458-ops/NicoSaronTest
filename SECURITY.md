# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Hi%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20security%20vulnerability%20in%20this%20project.%0A%0A-%20**Description%20of%20the%20vulnerability**%3A%20%5BEnter%20description%5D%0A-%20**Steps%20to%20reproduce**%3A%20%5BEnter%20steps%5D%0A-%20**Potential%20impact**%3A%20%5BEnter%20impact%5D%0A%0AThank%20you%20for%20your%20time.%0A%0A%5BYour%20Name%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, if your email client does not support automated links, you can copy the template below and send it manually:

### Vulnerability Report Template

```text
Subject: Security Vulnerability Report

Hi Security Team,

I would like to report a security vulnerability in this project.

- Description of the vulnerability: [Enter description]
- Steps to reproduce: [Enter steps]
- Potential impact: [Enter impact]

Thank you for your time.

[Your Name]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
