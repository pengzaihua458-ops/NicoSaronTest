## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [structured security report link](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20repository&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A) or directly to `security@example.com`.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If sending an unformatted email, please use the following template:

```text
[SECURITY REPORT] Vulnerability Title

Description:
<Detailed description of the security issue>

Steps to Reproduce:
1.
2.

Impact:
<Potential impact if exploited>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
