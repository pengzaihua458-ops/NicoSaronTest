# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Sentinel%3A%20Security%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%20e.g.%20Buffer%20Overflow%2C%20XSS%2C%20etc.%5D%0A%0ASeverity%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0ADescription%3A%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0AImpact%3A%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
