# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [Structured Security Vulnerability Report Email](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20Repository&body=Summary%3A%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%3A%0A%0APossible%20Fix%3A%0A).
3. If your email client does not support pre-filled mailto links, use the fallback template below and send your report to **security@example.com**:

```text
Subject: [SECURITY REPORT] Vulnerability in Repository

Summary:
[Brief summary of the vulnerability]

Steps to Reproduce:
1.
2.

Impact:
[Describe potential impact]

Possible Fix:
[Optional suggestion]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
