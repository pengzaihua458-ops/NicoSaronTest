# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](<mailto:security@example.com?subject=%5BSecurity%20Vulnerability%20Report%5D%20%3CComponent%2FSummary%3E&body=Description%3A%0A%0A%0ASteps%20to%20reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%3A%0A%0A%0AProposed%20fix%20(optional)%3A%0A>).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy and paste the following report template into your email client:

```markdown
### Security Vulnerability Report

**Component / Summary:**
[Brief description of affected component or issue]

**Description:**
[Detailed explanation of the vulnerability]

**Steps to Reproduce:**

1. [First Step]
2. [Second Step]

**Impact:**
[Potential security impact]

**Proposed Fix (Optional):**
[Suggested resolution or patch]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
