# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | ✅ Yes             |
| 1.0.x   | ❌ No              |
| < 1.0.0 | ❌ No              |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5Bvulnerability%20type%5D%0ASeverity%3A%20%5BHigh%2FMedium%2FLow%5D%0ADescription%3A%20%5Bdetailed%20description%5D%0ASteps%20to%20reproduce%3A%20%5Bsteps%5D%0AImpact%3A%20%5Bimpact%20on%20the%20application%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
