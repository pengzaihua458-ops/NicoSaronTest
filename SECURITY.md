## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue or discuss the issue publicly.
2. Email your findings using our [structured report template](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. Alternatively, copy and paste the format below into an email to `security@example.com`:

```text
Subject: Vulnerability Report

Description:
[Detailed description of the issue]

Steps to Reproduce:
1.
2.

Impact:
[Describe potential security impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
