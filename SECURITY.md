# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Use our [Security Vulnerability Report Template](mailto:security@example.com?subject=🛡️%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:) to email your findings.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We aim to acknowledge all security reports within 48 hours and provide a timeline for resolution. Thank you for helping keep this project secure!
