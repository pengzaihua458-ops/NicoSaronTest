# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| Main    | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=---%0AVulnerability%20Details%0A-%20Type%3A%20%5Be.g.%2C%20XSS%2C%20SQL%20Injection%5D%0A-%20Severity%3A%20%5Be.g.%2C%20Low%2C%20Medium%2C%20High%2C%20Critical%5D%0A%0ADescription%3A%0A%5BProvide%20a%20clear%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0AImpact%3A%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D).
3. Provide a detailed description of the vulnerability using the template provided in the email link above.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
