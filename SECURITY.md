# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

**Do not open a public issue.**

To report a vulnerability, please send an email to [security@example.com](mailto:security@example.com?subject=🛡️%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:) with the following information:

- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact if exploited.

## Response SLA

We will acknowledge receipt of your report within **48 hours** and provide an estimated timeline for a fix. We ask for your patience and cooperation as we work to resolve the issue securely.

Thank you for helping keep this project secure!
