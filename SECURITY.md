# Security Policy

## Supported Versions

Below are the versions of this project that are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to us using the pre-filled template link below:

   [**Report a Security Vulnerability**](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Type%20of%20vulnerability%3A%20%5BType%5D%0ASeverity%3A%20%5BCritical%2FHigh%2FMedium%2FLow%5D%0ADescription%3A%20%5BDescription%5D%0ASteps%20to%20reproduce%3A%20%5BSteps%5D%0AExpected%20vs%20Actual%20Behavior%3A%20%5BBehavior%5D%0AImpact%3A%20%5BImpact%5D)

3. Alternatively, copy and paste the following template into an email to [security@example.com](mailto:security@example.com):

   ```markdown
   Type of vulnerability: [Type]
   Severity: [Critical/High/Medium/Low]
   Description: [Description]
   Steps to reproduce: [Steps]
   Expected vs Actual Behavior: [Behavior]
   Impact: [Impact]
   ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
