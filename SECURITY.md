# Security Policy

## Supported Versions

We provide security updates for the following versions of the project:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%2C%20e.g.%20XSS%2C%20SQLi%5D%0A%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0ADescription%3A%0A%5BDetailed%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%0A2.%0A3.%0A%0AImpact%3A%0A%5BWhat%20could%20happen%20if%20this%20is%20exploited%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
