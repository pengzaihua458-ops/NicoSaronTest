# Security Policy

![Security Status](https://img.shields.io/badge/Security-Active-brightgreen.svg)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Reporting Template

If your email client does not support the link above, please use the following template for your report:

```markdown
**Description:**
[Provide a detailed description of the vulnerability]

**Steps to reproduce:**
1. [Step 1]
2. [Step 2]
3. [Step 3]

**Impact:**
[Describe the potential impact of this vulnerability]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
