## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Please%20describe%20the%20vulnerability%20and%20impact.).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Vulnerability Report Template

When submitting a security report, please include as much of the following information as possible:

- **Type of Issue:** (e.g. buffer overflow, SQL injection, cross-site scripting)
- **Component/Location:** File name, endpoint, or module affected
- **Steps to Reproduce:** Clear instructions or proof-of-concept script
- **Impact:** Potential threat or risk posed by the vulnerability
- **Suggested Fix:** (Optional) Any mitigation steps or patches

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
