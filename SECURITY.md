# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via our [Pre-filled Vulnerability Email Template](mailto:security@example.com?subject=%5BSECURITY%20VULNERABILITY%5D%20%3CBrief%20Description%3E&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A1.%0A2.%0A%0AImpact%3A%0A) or email [security@example.com](mailto:security@example.com).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template Fallback

If you are unable to use the mailto link, please copy and paste the following template into your email:

```text
Subject: [SECURITY VULNERABILITY] <Brief Description>

Description:
<Provide a summary of the issue>

Steps to Reproduce:
1. <Step 1>
2. <Step 2>

Impact:
<Describe potential impact>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
