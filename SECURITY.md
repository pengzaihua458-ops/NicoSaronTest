# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via email:
   - 📧 **[Draft a Security Report Email](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%20to%20help%20us%20understand%20and%20reproduce%20the%20issue%3A%0A%0A-%20**Type%20of%20Vulnerability**%3A%20%5Be.g.%20XSS%2C%20RCE%2C%20Auth%20Bypass%5D%0A-%20**Severity**%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20**Description**%3A%20%5BWhat%20is%20the%20vulnerability%3F%5D%0A-%20**Steps%20to%20Reproduce**%3A%20%5BProvide%20clear%20instructions%20or%20a%20PoC%5D%0A-%20**Impact**%3A%20%5BWhat%20can%20an%20attacker%20achieve%3F%5D)** (opens pre-filled email client)
   - Or manually email [security@example.com](mailto:security@example.com) using the template below.

### Security Report Template

If your system doesn't support `mailto` links, please copy and paste the following template into your email:

```text
Subject: 🛡️ Vulnerability Report

- **Type of Vulnerability**: [e.g. XSS, RCE, Auth Bypass]
- **Severity**: [Low / Medium / High / Critical]
- **Description**: [What is the vulnerability?]
- **Steps to Reproduce**: [Provide clear instructions or a PoC]
- **Impact**: [What can an attacker achieve?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
