# Security Policy

## Supported Versions

| Version | Supported        |
| ------- | ---------------- |
| 0.1.x   | ✅ Supported     |
| < 0.1   | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=%23%20Security%20Vulnerability%20Report%0A%0A%23%23%20Description%0A%5BDescribe%20the%20vulnerability%20here%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%0A2.%20%0A%0A%23%23%20Impact%0A%5BExplain%20the%20impact%20of%20this%20vulnerability%5D).
   - _Tip: Clicking the link above will pre-fill a template for you!_
3. Provide a detailed description of the vulnerability, including steps to reproduce.

## Disclosure Policy

- **Acknowledgement**: We aim to acknowledge receipt of your report within 2 business days.
- **Status Updates**: We will provide periodic updates on the status of your report.
- **Disclosure**: We ask that you do not disclose the vulnerability publicly until we have had a chance to address it.

Thank you for helping keep this project secure!
