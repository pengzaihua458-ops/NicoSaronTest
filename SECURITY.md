# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

### 🔍 1. Scan & Identify

- **Do not** open a public issue for security vulnerabilities.
- Document the vulnerability type and affected component.

### 🎯 2. Report Privately

- Email your findings to [security@example.com](<mailto:security@example.com?subject=Vulnerability%20Report&body=Vulnerability%20Type%3A%0A%0ASeverity%3A%0A%0AAffected%20Component(s)%3A%0A%0ADescription%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A%0A%0AMitigation%20Suggestions%3A>).
- Use the pre-filled template to ensure we have all the necessary information.

### ⏳ 3. Acknowledgment

- We will acknowledge receipt of your report within 48 hours.
- We will provide an initial assessment and estimated timeline for a fix within 7 business days.

Thank you for helping keep this project secure!
