## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via email using our [Structured Security Report Mailto Link](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. If mailto links are not supported by your client, copy and paste the following template when emailing `security@example.com`:

```text
Subject: [SECURITY] Vulnerability Report

Description:
<Provide a detailed description of the vulnerability>

Steps to Reproduce:
1. <Step 1>
2. <Step 2>

Impact:
<Describe the potential security impact>
```

We will acknowledge receipt of your report within 48 hours and provide regular updates on our progress. Thank you for helping keep this project secure!
