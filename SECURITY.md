## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us using one of the following methods:

1. **Do not** open a public issue.
2. Email your findings directly to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).

If the mailto link does not open automatically, please send an email to `security@example.com` using the fallback template below:

```text
Subject: Security Vulnerability Report

Description:
[Provide a clear description of the issue]

Steps to reproduce:
1.
2.
3.

Impact:
[Describe potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
