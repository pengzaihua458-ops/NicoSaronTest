## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send your report using our [vulnerability report email](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. If mailto links are not supported in your browser/client, email `security@example.com` with the following template:

```text
Subject: Vulnerability Report

Description:
[Provide details about the issue]

Steps to Reproduce:
1.
2.

Impact:
[Describe potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
