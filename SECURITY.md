# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com). For the best experience, you can use our **[Pre-filled Security Report Template](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%20to%20help%20us%20resolve%20this%20issue%20quickly%3A%0A%0A-%20Vulnerability%20Type%3A%20%5Be.g.%20XSS%2C%20RCE%2C%20SQLi%5D%0A-%20Severity%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20Description%3A%20%5BDescribe%20the%20issue%20in%20detail%5D%0A-%20Steps%20to%20Reproduce%3A%20%5BProvide%20clear%20steps%20or%20PoC%5D%0A-%20Impact%3A%20%5BWhat%20can%20an%20attacker%20do%20by%20exploiting%20this%3F%5D)** to open your mail client with a structured report format.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Fallback Copy-Paste Template

If the pre-filled template link does not work with your mail client, please copy and paste the markdown template below into an email to [security@example.com](mailto:security@example.com):

```markdown
Subject: 🛡️ Security Vulnerability Report

Please provide the following details to help us resolve this issue quickly:

- Vulnerability Type: [e.g. XSS, RCE, SQLi]
- Severity: [Low / Medium / High / Critical]
- Description: [Describe the issue in detail]
- Steps to Reproduce: [Provide clear steps or PoC]
- Impact: [What can an attacker do by exploiting this?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
