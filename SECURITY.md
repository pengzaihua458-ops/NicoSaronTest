## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send an email report using our [structured vulnerability report link](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. If your mail client does not support pre-filled links, email [security@example.com](mailto:security@example.com) using the fallback template below:

```text
Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:
1.
2.

Impact:
[Describe the potential security impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
