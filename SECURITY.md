# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings securely using our [Pre-formatted Security Report Template](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BType%20of%20Vulnerability%5D&body=Hello%2C%0A%0AI%20would%20like%20to%20report%20a%20security%20vulnerability.%0A%0A---%0A%0A%23%23%20Vulnerability%20Details%0A%0A-%20%2A%2AType%2A%2A%3A%20%5BType%20of%20Vulnerability%5D%0A-%20%2A%2ASeverity%2A%2A%3A%20%5BLow%20/%20Medium%20/%20High%20/%20Critical%5D%0A-%20%2A%2AAffected%20Component%2A%2A%3A%20%5BComponent%20or%20File%20Path%5D%0A%0A%23%23%20Description%0A%5BPlease%20describe%20the%20vulnerability%20in%20detail.%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A3.%20%5BStep%203%5D%0A%0A%23%23%20Impact%0A%5BWhat%20can%20an%20attacker%20achieve%20by%20exploiting%20this%3F%5D%0A%0A%23%23%20Proposed%20Remediation%20%28Optional%29%0A%5BHow%20can%20we%20fix%20this%20issue%3F%5D%0A%0A---%0A%0AThank%20you%20for%20helping%20keep%20the%20project%20secure%21) email link.

   *Alternatively, you can manually email [security@example.com](mailto:security@example.com) with the template information.*

3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
