# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Submit your findings via [GitHub Security Advisories](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new).
3. If you are unable to use the advisory tool, email your findings to [security@example.com](mailto:security@example.com) using the template below.

### Response Timeline

- **Acknowledgment:** Within 48 hours.
- **Initial Assessment:** Within 7 business days.
- **Fix/Advisory:** Timeline depends on severity and complexity.

### Reporting Template

Please include as much information as possible to help us understand and resolve the issue:

- **Vulnerability Type:** (e.g., SQL Injection, XSS, etc.)
- **Severity Assessment:** (Critical/High/Medium/Low)
- **Affected Components:** (e.g., specific files or API endpoints)
- **Description:** A detailed explanation of the vulnerability.
- **Steps to Reproduce:** Clear, numbered steps to demonstrate the issue.
- **Proof of Concept:** (If available, e.g., code snippets or screenshots)
- **Impact:** What could an attacker achieve?
- **Suggested Mitigation:** (Optional) How do you think this should be fixed?

Thank you for helping keep this project secure!
