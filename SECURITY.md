# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to security@example.com using our [Structured Vulnerability Report Email Link](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Dear%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20potential%20security%20vulnerability%20in%20this%20project.%0A%0A-%20**Vulnerability%20Type%3A**%20%5BType%2C%20e.g.%2C%20XSS%2C%20RCE%2C%20etc.%5D%0A-%20**Severity%3A**%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A###%20Description%0A%5BPlease%20describe%20the%20vulnerability%20in%20detail.%5D%0A%0A###%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A###%20Impact%0A%5BWhat%20is%20the%20potential%20impact%20or%20risk%20associated%20with%20this%20vulnerability%3F%5D%0A%0AThank%20you%20for%20your%20cooperation%21).
3. Alternatively, you can compose an email to `security@example.com` manually with:
   - A detailed description of the vulnerability.
   - Severity level estimate (Low, Medium, High, Critical).
   - Clear steps to reproduce.
   - The potential security impact.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
