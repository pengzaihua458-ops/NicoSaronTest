# 🛡️ Security Policy

## Supported Versions

We are committed to the security of our project. We currently provide security updates for the following versions:

| Version | Supported      |
| ------- | -------------- |
| 1.0.x   | ✅ Supported   |
| < 1.0.0 | ❌ Unsupported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it immediately via the following channels:

### 1. Preferred: GitHub Security Advisory (GHSA)

The most secure way to report a vulnerability is to create a draft security advisory at:
[https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new)

### 2. Alternative: Email

If you are unable to use GHSA, please email your findings to [security@example.com](<mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BType%20of%20Vulnerability%5D&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Vulnerability%20Type%3A%20%0A-%20Severity%3A%20%0A-%20Affected%20Component(s)%3A%20%0A-%20Description%3A%20%0A-%20Steps%20to%20Reproduce%3A%20%0A-%20Proof%20of%20Concept%3A%20%0A-%20Impact%3A%20%0A-%20Suggested%20Mitigation%3A>).

## Our Security Commitment

- **48-hour Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **7-Business-Day Assessment:** We will provide an initial assessment of the vulnerability within 7 business days.
- **Triage & Resolution:** High-severity issues are triaged immediately and addressed in order of impact.

## Vulnerability Report Template

Please include the following information in your report to help us triage and resolve the issue quickly:

- **Vulnerability Type:** (e.g., XSS, SQL Injection, Buffer Overflow)
- **Severity:** (e.g., Low, Medium, High, Critical)
- **Affected Component(s):** (e.g., API endpoint, specific UI component)
- **Description:** A clear and concise description of the security issue.
- **Steps to Reproduce:** Detailed steps to demonstrate the vulnerability.
- **Proof of Concept (PoC):** Any scripts, screenshots, or sample data that help demonstrate the issue.
- **Impact:** What could an attacker achieve by exploiting this vulnerability?
- **Suggested Mitigation:** If known, please suggest a way to fix the issue.

**Please do not open public issues for security vulnerabilities.** This allows us to address the issue before it is publicly disclosed, protecting all users.
