# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings directly to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BTitle%20of%20Issue%5D&body=Type%3A%20%5BType%20of%20vulnerability%2C%20e.g.%2C%20XSS%2C%20CSRF%2C%20etc.%5D%0A%0ASeverity%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0ADescription%3A%0A%5BPlease%20describe%20what%20the%20vulnerability%20is%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0AImpact%3A%0A%5BWhat%20is%20the%20potential%20impact%20of%20this%20vulnerability%5D) (this structured link automatically pre-fills a report template to minimize back-and-forth).
3. If the mailto link does not work, please manually copy the following template and send it to **security@example.com**:

   ```text
   Subject: 🛡️ Vulnerability Report: [Title of Issue]

   Type: [Type of vulnerability, e.g., XSS, CSRF, etc.]
   Severity: [Low / Medium / High / Critical]

   Description:
   [Please describe what the vulnerability is]

   Steps to Reproduce:
   1.
   2.
   3.

   Impact:
   [What is the potential impact of this vulnerability]
   ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
