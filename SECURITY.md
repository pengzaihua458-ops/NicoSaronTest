# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](<mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report%20-%20%5BBrief%20Description%5D&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Vulnerability%20Type%3A%20%5Be.g.%20XSS%2C%20RCE%5D%0A-%20Affected%20Component%2FVersion%3A%20%5Bspecify%20file%20or%20module%5D%0A-%20Severity%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%20Impact%0A%5BWhat%20can%20an%20attacker%20do%20with%20this%20vulnerability%3F%5D%0A%0A%23%23%20Proposed%20Remediation%20(Optional)%0A%5BHow%20to%20fix%20it%5D>).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If you prefer not to use the link above, you can copy and paste the template below into your email:

```text
Subject: [SECURITY] Vulnerability Report - [Brief Description]

Please provide the following details:

- Vulnerability Type: [e.g. XSS, RCE]
- Affected Component/Version: [specify file or module]
- Severity: [Low / Medium / High / Critical]

## Steps to Reproduce
1. [Step 1]
2. [Step 2]

## Impact
[What can an attacker do with this vulnerability?]

## Proposed Remediation (Optional)
[How to fix it]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
