## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings directly using our [Structured Security Vulnerability Report Email](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Vulnerability%20Type%3A%0A%0AComponent%2FLocation%3A%0A%0ASeverity%3A%0A%0ADescription%3A%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0APotential%20Impact%3A%0A%0ASuggested%20Fix%20%28optional%29%3A%0A).
3. Alternatively, copy and fill out the fallback report template below and email it to `security@example.com`.

### Fallback Vulnerability Report Template

```text
Subject: [SECURITY] Vulnerability Report

Vulnerability Type: [e.g., Remote Code Execution, Information Disclosure]
Component/Location: [e.g., URL, file path, parameter name]
Severity: [Low / Medium / High / Critical]

Description:
[Provide a clear summary of the issue]

Steps to Reproduce:
1.
2.
3.

Potential Impact:
[Describe what an attacker could achieve]

Suggested Fix (optional):
[Any recommended remediation steps]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
