# Security Policy

![Security Policy](https://img.shields.io/badge/Security_Policy-Active-success)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=###%20Description%0A%0A###%20Steps%20to%20Reproduce%0A%0A###%20Impact).
3. You can use the template below for your report.

### Reporting Template

If your email client does not support pre-filled links, please use the following template:

```markdown
### Description

A clear and concise description of what the vulnerability is.

### Steps to Reproduce

1. Step one
2. Step two
3. Step three

### Impact

What is the potential impact of this vulnerability?
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
