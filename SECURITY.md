## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=🛡️ Security Vulnerability Report&body=Description:%0A%0ASteps to reproduce:).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix (usually within 48 hours). Thank you for helping keep this project secure!
