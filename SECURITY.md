# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send an email to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Type%20of%20Vulnerability%3A%0A%5BDescribe%20the%20vulnerability%20type%5D%0A%0ASeverity%3A%0A%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0ADescription%3A%0A%5BProvide%20a%20detailed%20description%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%2FScope%3A%0A%5BWhat%20is%20the%20potential%20impact%5D) using our pre-filled template.
3. If the link above does not open in your client, please copy and paste the template below into an email to **security@example.com**:

```text
Subject: 🛡️ Vulnerability Report

Type of Vulnerability:
[Describe the vulnerability type, e.g., XSS, CSRF, RCE, Information Disclosure]

Severity:
[Low / Medium / High / Critical]

Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:
1.
2.

Impact/Scope:
[What is the potential impact and scope of exploitation]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
