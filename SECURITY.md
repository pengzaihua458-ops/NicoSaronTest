# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the findings via one of the following methods:
   - **Option A: One-Click Email (Recommended)**
     Use our pre-filled email template to quickly report the issue:
     [Report Security Vulnerability](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%20to%20help%20us%20understand%20and%20resolve%20the%20issue%20quickly%3A%0A%0A-%20**Vulnerability%20Type%3A**%20%5Be.g.%2C%20XSS%2C%20RCE%2C%20SQLi%5D%0A-%20**Severity%3A**%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20**Description%3A**%20%5BProvide%20a%20detailed%20description%5D%0A-%20**Steps%20to%20Reproduce%3A**%20%5BStep-by-step%20instructions%5D%0A-%20**Impact%3A**%20%5BWhat%20is%20the%20potential%20impact%3F%5D)

   - **Option B: Manual Email**
     Send an email to **security@example.com** with the template below:

     ```markdown
     Subject: Security Vulnerability Report

     Please provide the following details to help us understand and resolve the issue quickly:

     - **Vulnerability Type:** [e.g., XSS, RCE, SQLi]
     - **Severity:** [Low / Medium / High / Critical]
     - **Description:** [Provide a detailed description]
     - **Steps to Reproduce:** [Step-by-step instructions]
     - **Impact:** [What is the potential impact?]
     ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
