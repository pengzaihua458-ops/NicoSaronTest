## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A%0A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If mailto links do not work in your client, please copy and paste the template below into an email to `security@example.com`:

```text
Subject: [SECURITY REPORT] Vulnerability Report

Description:
[Provide a clear description of the issue]

Steps to Reproduce:
1.
2.
3.

Impact:
[Describe potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
