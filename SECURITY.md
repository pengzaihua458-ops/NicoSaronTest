# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%5D%0ASeverity%3A%20%5BCritical%2FHigh%2FMedium%2FLow%5D%0ADescription%3A%20%5BDetailed%20description%5D%0ASteps%20to%20reproduce%3A%20%5BStep-by-step%20guide%5D%0AImpact%3A%20%5BPotential%20impact%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
