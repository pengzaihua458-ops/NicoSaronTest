# Security Policy

## Reporting a Vulnerability

We value the work of security researchers and take the security of this project seriously. If you believe you have found a security vulnerability, please report it via the [GitHub Security Advisory channel](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) for a safe and private disclosure process.

Alternatively, you may:

1.  **Do not** open a public issue.
2.  Email your findings to `security@example.com` (note: the GitHub advisory link above is preferred for faster triage).
3.  Include a detailed description, steps to reproduce, and any potential impact in your report.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
