# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BInsert%20Short%20Description%5D&body=Thank%20you%20for%20helping%20keep%20our%20project%20secure%21%0A%0A%23%23%20Vulnerability%20Details%0A-%20**Type**%3A%20%5Be.g.%20XSS%2C%20RCE%2C%20Authentication%20Bypass%2C%20etc.%5D%0A-%20**Severity**%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20**Affected%20Version%2FComponent**%3A%20%5Be.g.%20v1.0.0%2C%20login%20form%20component%5D%0A%0A%23%23%20Description%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%20and%20its%20impact%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A3.%20%5BStep%203%5D%0A%0A%23%23%20Proof%20of%20Concept%0A%5BProvide%20any%20relevant%20code%2C%20payloads%2C%20or%20screenshots%5D%0A%0A%23%23%20Proposed%20Remediation%20%28Optional%29%0A%5BIf%20you%20have%20suggestions%20on%20how%20to%20fix%20the%20issue%2C%20please%20describe%20them%20here%5D) (this link will pre-fill the email template for you!).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

If the link above does not work or if you prefer to draft the email manually, please copy and paste the template below into your email client:

```markdown

Thank you for helping keep our project secure!

## Description

## Steps to Reproduce

2. [Step 2]
3. [Step 3]

## Proof of Concept
[Provide any relevant code, payloads, or screenshots]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
