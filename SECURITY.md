# Security Policy

## Supported Versions

The table below outlines the security support status for recent versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BInsert%20Short%20Description%5D&body=Hello%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20potential%20security%20vulnerability%20in%20the%20repository.%0A%0A%23%23%20Description%0A%5BDescribe%20the%20vulnerability%20here%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%20Impact%0A%5BDescribe%20the%20potential%20impact%20here%5D%0A%0AThank%20you%21).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy and paste the fallback template below into your email client:

```text
Subject: 🛡️ Vulnerability Report: [Insert Short Description]

Hello Security Team,

I would like to report a potential security vulnerability in the repository.

## Description
[Describe the vulnerability here]

## Steps to Reproduce
1. [Step 1]
2. [Step 2]

## Impact
[Describe the potential impact here]

Thank you!
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
