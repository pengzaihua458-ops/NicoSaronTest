# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via email using our [Pre-filled Vulnerability Report Email](mailto:security@example.com?subject=%5BVulnerability%20Report%5D%20Security%20Issue%20in%20Repository&body=Component%2FArea%3A%0A%0ADescription%3A%0A%0ASteps%20to%20reproduce%3A%0A1.%0A2.%0A3.%0A%0AImpact%3A%0A) or directly to `security@example.com`.

### Report Template

If your mail client does not support pre-filled links, please use the template below:

```text
Subject: [Vulnerability Report] Security Issue in Repository

Component/Area:
[Specify affected area]

Description:
[Provide a clear description of the vulnerability]

Steps to reproduce:
1.
2.
3.

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
