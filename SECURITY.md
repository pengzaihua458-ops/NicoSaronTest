# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported        |
| ------- | ---------------- |
| v1.0.x  | ✅ Supported     |
| < v1.0  | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using this [pre-filled template](mailto:security@example.com?subject=🛡️%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:) or directly to [security@example.com](mailto:security@example.com).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We aim to acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
