# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We commit to acknowledging receipt of your report within 48-72 hours and will provide an estimated timeline for a fix. Thank you for helping keep this project secure!
