## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via the [GitHub Security Advisory](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) (Preferred).
3. Alternatively, email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A).

### What to expect

- **Acknowledgement:** Within 48 hours.
- **Triage:** Initial assessment within 5 business days.
- **Resolution:** We aim to resolve all critical vulnerabilities within 30 days.

Thank you for helping keep this project secure!
