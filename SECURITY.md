# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [pre-formatted security report email](mailto:security@example.com?subject=%5BVulnerability%20Report%5D%20%5BComponent%2FModule%5D&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0AImpact%3A%0A%0ASuggested%20Fix%3A%0A) (`security@example.com`).
3. If your mail client does not support pre-filled links, please use the report template below:

```text
Subject: [Vulnerability Report] [Component/Module]

Description:
<Clear and concise description of the issue>

Steps to Reproduce:
1.
2.
3.

Impact:
<Potential security impact>

Suggested Fix:
<Optional recommendation>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
