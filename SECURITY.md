## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send your report via [email to security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Please%20describe%20the%20vulnerability%20and%20steps%20to%20reproduce.).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If you are unable to use the mailto link above, please copy and paste the following template into an email to `security@example.com`:

```
Subject: Vulnerability Report - [Short Summary]

Description:
[Detailed description of the vulnerability]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Impact:
[Describe potential impact]

Suggested Fix (optional):
[Your recommendations]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
