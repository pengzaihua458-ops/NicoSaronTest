# Security Policy

## Supported Versions

Below are the currently supported versions of this project. If you are using an unsupported version, we recommend updating to a supported version immediately.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Type%20of%20Vulnerability%3A%0A-%20Severity%3A%0A-%20Description%3A%0A-%20Steps%20to%20Reproduce%3A%0A-%20Impact%3A).
3. Alternatively, copy and paste the template below into an email:

```text
Type of Vulnerability: [e.g., XSS, SQLi, Buffer Overflow]
Severity: [Low/Medium/High/Critical]
Description: [Provide a detailed description]
Steps to Reproduce:
1.
2.
3.
Impact: [What could happen if exploited]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
