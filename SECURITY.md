# Security Policy

![Security Policy](https://img.shields.io/badge/Security-Policy-brightgreen)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report:%20[Brief%20Description]&body=###%20Description%0A[Describe%20the%20vulnerability]%0A%0A###%20Reproduction%20Steps%0A[How%20to%20reproduce]%0A%0A###%20Impact%0A[What%20is%20the%20impact]).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Reporting Template (Alternative)

If your email client does not support pre-filled links, please use the following template for your report:

```markdown
### Description

[Describe the vulnerability]

### Reproduction Steps

[How to reproduce]

### Impact

[What is the impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
