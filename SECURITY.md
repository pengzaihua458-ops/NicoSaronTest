## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If sending an email directly, please use the following structure:

```markdown
**Vulnerability Type:** [e.g. XSS, Auth Bypass, Secret Exposure]
**Component/Location:** [e.g. API endpoint, configuration file]
**Impact:** [Description of potential security impact]

**Steps to Reproduce:**

1.
2.
3.

**Suggested Fix / Remediation:**
```

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
