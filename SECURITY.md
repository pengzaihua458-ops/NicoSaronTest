## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us:

### 🛠️ Reporting Steps

1.  **Stay Private**: Do not open a public issue for security vulnerabilities.
2.  **Email Us**: Send your report to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:).
3.  **Be Detailed**: Please include a description, steps to reproduce, and the potential impact.

We will acknowledge receipt of your report (typically within 48 hours) and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
