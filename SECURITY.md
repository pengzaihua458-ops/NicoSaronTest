# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send your report via email using our [Pre-filled Security Email Template](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. Alternatively, send an email to `security@example.com` using the following report structure:

```text
Subject: [SECURITY] Vulnerability Report

Description:
[Provide a clear description of the issue]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report within 48 hours and provide regular updates on our progress toward resolving the issue. Thank you for helping keep this project secure!
