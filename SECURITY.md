# Security Policy

## Supported Versions

The following versions of our project are currently being supported with security updates:

| Version | Supported        |
| ------- | ---------------- |
| 1.0.x   | ✅ Supported     |
| < 1.0.0 | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the vulnerability via email to [security@example.com](mailto:security@example.com?subject=🛡️%20Security%20Vulnerability%20Report&body=Description:%0A%0A%0ASteps%20to%20reproduce:%0A%0A).

### What to expect

- We will acknowledge receipt of your report within 48 hours.
- We will provide an estimated timeline for a fix.
- We will keep you informed of our progress.

Thank you for helping keep this project secure!
