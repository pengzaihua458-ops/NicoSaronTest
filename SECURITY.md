# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the findings via email to [security@example.com](<mailto:security@example.com?subject=Vulnerability%20Report&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Type%20of%20Vulnerability%3A%20%0A-%20Severity%20(Low%2FMedium%2FHigh%2FCritical)%3A%20%0A-%20Description%3A%20%0A-%20Steps%20to%20Reproduce%3A%20%0A-%20Impact%3A%20>). Click the link to automatically open your email client with a pre-filled reporting template.
3. If the link above does not work with your mail client, please email **security@example.com** using the template below:

```text
Subject: Vulnerability Report

- Type of Vulnerability:
- Severity (Low/Medium/High/Critical):
- Description:
- Steps to Reproduce:
- Impact:
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
