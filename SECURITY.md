# Security Policy

## Supported Versions

Below are the versions of this project that are currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| < 1.0   | ❌ No     |
| >= 1.0  | ✅ Yes    |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%20of%20the%20vulnerability%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AExpected%20vs%20actual%20behavior%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Fallback / Manual Instructions

If the email link above does not work with your mail client, please send an email to **security@example.com** with the following template:

```text
Subject: Vulnerability Report

Description of the vulnerability:
[Provide a detailed description of the security issue]

Steps to reproduce:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Expected vs actual behavior:
[Provide information on what you expected versus what actually happened]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
