# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Use our [Pre-filled Email Template](mailto:security@example.com?subject=Vulnerability%20Report&body=Type%3A%20%0ASeverity%3A%20%0ADescription%3A%20%0A%0ASteps%20to%20Reproduce%3A%20%0A1.%20%0A2.%20%0A%0AImpact%3A%20) to send your report directly to [security@example.com](mailto:security@example.com).
3. If your email client does not support structured `mailto` links, please copy and fill out the fallback template below and email it to **security@example.com**.

### Vulnerability Report Template

```text
Type: [e.g., XSS, SQL Injection, Auth Bypass]
Severity: [Low / Medium / High / Critical]
Description: [Provide a detailed description of the vulnerability]

Steps to Reproduce:
1. [First Step]
2. [Second Step]

Impact: [What is the potential impact of this vulnerability?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
