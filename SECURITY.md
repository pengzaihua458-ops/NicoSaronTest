# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **GitHub Security Advisory (Preferred)**: [Submit a new report](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) via GitHub's secure channel.
2. **Email (Fallback)**: If you prefer email, send your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AExpected%20Behavior%3A%0A%0AActual%20Behavior%3A%0A%0AImpact%3A).

### Do Not Open Public Issues

Please **do not** open a public issue for security vulnerabilities. Using the channels above ensures that vulnerabilities are handled discreetly and resolved before they are made public.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
