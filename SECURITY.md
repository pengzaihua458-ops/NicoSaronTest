# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Main    | ✅        |
| < 1.0.0 | ❌        |

## Reporting a Vulnerability

1. **Do not** open a public issue.
2. Email [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:).
3. Provide details and reproduction steps.

Reports are acknowledged within 48-72 hours.
