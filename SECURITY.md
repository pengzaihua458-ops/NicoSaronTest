# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [pre-filled security report template](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20Repository&body=Title%3A%20%0A%0ADescription%3A%20%0A%0ASteps%20to%20reproduce%3A%20%0A%0AImpact%3A%20) or directly to `security@example.com`.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If your mail client does not support pre-filled links, please use the following structure in your email:

```text
Subject: [SECURITY REPORT] Vulnerability in Repository

Title: <Brief summary>
Description: <Detailed description of the vulnerability>
Steps to Reproduce:
1. <Step 1>
2. <Step 2>
Impact: <Impact of the issue>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
