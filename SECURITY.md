# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via email to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Describe%20the%20vulnerability%20including%20steps%20to%20reproduce.).
3. Alternatively, copy and paste the fallback template below to email us manually at **security@example.com**:

### Reporting Fallback Template

```markdown
Subject: Vulnerability Report - [Brief Title]

Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:

1.
2.
3.

Impact:
[Describe the potential impact of this vulnerability]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
