## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A).
3. Provide a detailed description of the vulnerability using the template below.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!

### Report Template

If your mail client does not support pre-filled mailto links, please include the following in your email:

```text
Description:
[Detailed description of the vulnerability]

Steps to Reproduce:
1.
2.
3.

Impact:
[Describe potential security impact]
```
