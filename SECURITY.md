## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com).
   - ⚡ **Tip:** You can use this **[Pre-filled Email Template](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BEnter%20Short%20Description%20Here%5D&body=Hello%20Security%20Team%2C%0A%0AI%20have%20discovered%20a%20security%20vulnerability%20in%20the%20project.%0A%0A%23%23%20Vulnerability%20Details%0A-%20**Severity**%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20**Component%20affected**%3A%20%5BName%20of%20file%2Fcomponent%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%20Impact%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D%0A%0A%23%23%20Proposed%20Fix%20(Optional)%0A%5BHow%20this%20could%20be%20fixed%5D%0A%0AThank%20you%21)** to draft your report automatically.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy and paste the template below:

```text
Subject: 🛡️ Vulnerability Report: [Enter Short Description Here]

Hello Security Team,

I have discovered a security vulnerability in the project.

2. [Step 2]

## Impact
[Describe the potential impact of this vulnerability]

## Proposed Fix (Optional)
[How this could be fixed]

Thank you!
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
