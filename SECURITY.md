## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via email using our [Structured Security Report Template](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A).
3. If you are unable to use the mailto link, please copy and paste the following template into an email to `security@example.com`:

```text
Description:
[Provide a clear description of the vulnerability]

Steps to Reproduce:
[Detailed steps to reproduce the issue]

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
