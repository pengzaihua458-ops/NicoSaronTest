# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Supported       |
| < 1.0.x | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via [our secure reporting template](mailto:security@example.com?subject=Vulnerability%20Report&body=###%20Description%0A%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0A###%20Steps%20to%20Reproduce%0A%0A1.%20%0A2.%20%0A3.%20%0A%0A###%20Expected%20Behavior%0A%0A%5BWhat%20should%20have%20happened%5D%0A%0A###%20Actual%20Behavior%0A%0A%5BWhat%20actually%20happened%5D%0A%0A###%20Impact%0A%0A%5BWhat%20is%20the%20potential%20impact%20of%20this%20vulnerability%3F%5D) or email [security@example.com](mailto:security@example.com).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!

## Reporting Template

If your mail client does not support the interactive link above, please use the following template in your email:

```markdown
### Description
[Provide a detailed description of the vulnerability]

### Steps to Reproduce
1. [Step 1]
2. [Step 2]
3. [Step 3]

### Expected Behavior
[What should have happened]

### Actual Behavior
[What actually happened]

### Impact
[What is the potential impact of this vulnerability?]
```
