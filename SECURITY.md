# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the vulnerability via email:
   - **Recommended:** Send a pre-formatted email using our [Structured Vulnerability Report Link](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20Vulnerability%5D%0A%0ASeverity%3A%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0ADescription%3A%0A%5BPlease%20describe%20the%20vulnerability%20in%20detail%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0AImpact%3A%0A%5BWhat%20is%20the%20potential%20impact%20of%20this%20vulnerability%3F%5D).
   - **Alternative:** Email us directly at [security@example.com](mailto:security@example.com) using the template provided below.

### Vulnerability Report Template

Please copy and paste the following template when sending manual reports:

```text
Subject: 🛡️ Vulnerability Report

Type: [Type of Vulnerability]

Severity: [Low / Medium / High / Critical]

Description:
[Please describe the vulnerability in detail]

Steps to Reproduce:
1.
2.
3.

Impact:
[What is the potential impact of this vulnerability?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
