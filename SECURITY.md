# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%2C%20e.g.%2C%20XSS%2C%20SQL%20Injection%5D%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0ADescription%3A%20%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0ASteps%20to%20Reproduce%3A%20%5BProvide%20clear%2C%20step-by-step%20instructions%5D%0AImpact%3A%20%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
