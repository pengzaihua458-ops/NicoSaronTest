# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [**Submit a Vulnerability Report**](mailto:security@example.com?subject=Vulnerability%20Report&body=%23%23%20Vulnerability%20Details%0A-%20**Type**%3A%20%0A-%20**Severity**%3A%20%0A%0A%23%23%20Description%0A%5BDescribe%20the%20vulnerability%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%0A2.%20%0A%0A%23%23%20Impact%0A%5BDescribe%20the%20impact%5D) via email.
3. Ensure your report includes a detailed description, severity, and clear steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
