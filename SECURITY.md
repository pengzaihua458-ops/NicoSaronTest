# Security Policy

## Supported Versions

The table below outlines the security support lifecycle for different versions of this project:

| Version | Supported |
| ------- | --------- |
| v1.0.x  | ✅ Yes    |
| < v1.0  | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the vulnerability directly to our team:
   - **Recommended:** [Report via Email](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Dear%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20security%20vulnerability.%0A%0A%23%23%20Vulnerability%20Details%0A-%20**Type%3A**%20%5Be.g.%20XSS%2C%20RCE%2C%20etc.%5D%0A-%20**Severity%3A**%20%5Be.g.%20Low%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A%23%23%20Description%0A%5BDescribe%20the%20issue%20in%20detail%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%20Impact%0A%5BExplain%20what%20an%20attacker%20could%20do%5D%0A%0A%5BYour%20Name%2FHandle%5D)
   - Alternatively, copy and paste the template below and email it to [security@example.com](mailto:security@example.com) with the subject `🛡️ Vulnerability Report`.

### Vulnerability Report Template

```markdown
## Vulnerability Details

- **Type:** [e.g. XSS, RCE, SQLi]
- **Severity:** [e.g. Low / Medium / High / Critical]

## Description

[Provide a detailed description of the vulnerability]

## Steps to Reproduce

1. [Step 1]
2. [Step 2]

## Impact

[Explain what an attacker could do with this vulnerability]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
