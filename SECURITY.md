# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%2C%20e.g.%2C%20XSS%2C%20RCE%5D%0A%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0ADescription%3A%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0AImpact%3A%0A%5BWhat%20harm%20could%20a%20successful%20exploit%20cause%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Email Report Template Fallback

If the `mailto:` link above does not open in your mail client, please copy and paste the template below into your email:

```text
Subject: 🛡️ Vulnerability Report

Type: [Type of vulnerability, e.g., XSS, RCE]

Severity: [Low/Medium/High/Critical]

Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]

Impact:
[What harm could a successful exploit cause?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
