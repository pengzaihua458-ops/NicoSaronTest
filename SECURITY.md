## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send an email using our [Structured Security Report Template](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20Repository&body=Component%2FArea%3A%0ADescription%3A%0ASteps%20to%20Reproduce%3A%0AImpact%3A) or mail to `security@example.com`.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Copy-Paste Report Template

If your mail client does not support pre-filled links, copy and paste the template below:

```text
Subject: [SECURITY REPORT] Vulnerability in Repository

Component/Area:
Description:
Steps to Reproduce:
Impact:
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
