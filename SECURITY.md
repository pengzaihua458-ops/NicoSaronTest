# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A1.%0A2.%0A3.%0A%0AImpact%3A%0A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

If your email client does not support mailto parameters, please use the following template when emailing your report:

```text
Subject: [SECURITY] Vulnerability Report

Description:
[Provide a brief summary of the security vulnerability]

Steps to Reproduce:
1. [First step]
2. [Second step]
3. [Third step]

Impact:
[Describe the potential impact of this vulnerability]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
