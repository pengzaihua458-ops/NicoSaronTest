# Security Policy

![Security Policy](https://img.shields.io/badge/Security%20Policy-Active-brightgreen.svg)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description:%0A%0AReproduction%20Steps:%0A%0AImpact:).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Reporting Template (Alternative)

If you cannot use the link above, please use the following template for your report:

- **Description:** A brief summary of the vulnerability.
- **Reproduction Steps:** Steps to demonstrate the issue.
- **Impact:** What can be achieved by exploiting this vulnerability?

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
