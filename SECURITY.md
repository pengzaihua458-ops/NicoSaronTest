## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using this link: [Report Security Vulnerability](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Potential%20Vulnerability%20Found&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A).
3. Alternatively, email `security@example.com` directly using the template below.

### Report Template

```text
Subject: [SECURITY REPORT] Potential Vulnerability Found

Description:
[Provide a clear description of the issue]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
