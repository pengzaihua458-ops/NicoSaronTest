## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send an email to [security@example.com](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20Repository&body=Please%20describe%20the%20vulnerability%2C%20impact%2C%20and%20steps%20to%20reproduce.) using our pre-filled template.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy and paste the report template below:

### Report Template

```text
Subject: [SECURITY REPORT] Vulnerability in Repository

Description:
[Provide a summary of the security vulnerability]

Impact:
[Describe the potential impact of this issue]

Steps to Reproduce:
1. [First Step]
2. [Second Step]
3. [Third Step]

Mitigation / Proposed Fix:
[Optional: Suggestions on how to fix the issue]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
