# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=---%0AType%3A%20%5Be.g.%2C%20SQL%20Injection%2C%20XSS%5D%0ASeverity%3A%20%5BLow%2C%20Medium%2C%20High%2C%20Critical%5D%0ADescription%3A%20%5BWhat%20is%20the%20issue%3F%5D%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0AImpact%3A%20%5BWhat%20can%20an%20attacker%20do%3F%5D%0A---).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
