# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [Report via Email](mailto:security@example.com?subject=Vulnerability%20Report&body=Description:%0A%0AReproduction%20Steps:%0A%0AImpact:) or email your findings to security@example.com.

### Reporting Template

If your email client does not support pre-filled links, please use the following template to ensure we have all the necessary information:

```markdown
### Description
[Describe the vulnerability]

### Reproduction Steps
[How to reproduce the issue]

### Impact
[What is the potential impact of this vulnerability]
```

3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
