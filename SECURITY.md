# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BSummary%20of%20Issue%5D&body=Hello%20Security%20Team%2C%0A%0AI%20have%20found%20a%20potential%20security%20vulnerability%20in%20the%20NicoSaronTest%20project.%0A%0A###%20Description%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0A###%20Steps%20to%20Reproduce%0A1.%20%5BFirst%20Step%5D%0A2.%20%5BSecond%20Step%5D%0A%0A###%20Impact%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D%0A%0AThank%20you%20for%20your%20hard%20work%20keeping%20the%20project%20secure!).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
