# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [pre-filled security report email](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A) (`security@example.com`).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If your mail client does not support pre-filled links, please use the following structure when sending your report:

```text
Subject: [SECURITY] Vulnerability Report

Description:
<Provide a detailed summary of the vulnerability>

Steps to Reproduce:
1. <Step 1>
2. <Step 2>

Impact:
<Describe potential security impact>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
