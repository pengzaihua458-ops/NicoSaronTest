# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the vulnerability via [GitHub Security Advisories](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new).
3. If you cannot use GitHub Security Advisories, email your findings to [security@example.com](mailto:security@example.com).

### Vulnerability Report Template

When reporting a vulnerability, please include the following information:

- **Description:** A detailed description of the vulnerability.
- **Impact:** What could happen if this vulnerability is exploited?
- **Steps to Reproduce:** Clear, step-by-step instructions to reproduce the issue.
- **Environment:** (Optional) Relevant details about the environment where the issue was found (e.g., Node.js version, OS).
- **Proof of Concept:** (Optional) Any scripts or screenshots that demonstrate the vulnerability.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
