## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Vulnerability%20Type%3A%0AComponent%3A%0ASteps%20to%20Reproduce%3A%0AImpact%3A%0AMitigation%2FSuggested%20Fix%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If the link above does not open your mail client, please copy and paste the template below into your report:

```text
Vulnerability Type:
Component:
Steps to Reproduce:
Impact:
Mitigation / Suggested Fix:
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
