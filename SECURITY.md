# Security Policy

## Supported Versions

| Version | Supported        |
| ------- | ---------------- |
| Main    | ✅ Supported     |
| < 1.0   | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=🛡️%20Security%20Vulnerability%20Report&body=Description:%0A%0ASteps%20to%20reproduce:).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We commit to investigating and responding to all vulnerability reports within 48-72 hours. We will provide an estimated timeline for a fix and keep you updated throughout the process. Thank you for helping keep this project secure!
