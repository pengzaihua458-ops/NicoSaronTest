# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us:

1. **GitHub Security Advisory (Preferred)**
   Please report vulnerabilities via the [GitHub Security Advisory](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) page. This is the most secure way to report vulnerabilities and allows us to coordinate a fix privately.

2. **Email (Fallback)**
   If you are unable to use GitHub Security Advisories, you can email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AExpected%20Behavior%3A%0A%0AActual%20Behavior%3A%0A%0AImpact%3A).

Please include a detailed description of the vulnerability, including steps to reproduce. We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
