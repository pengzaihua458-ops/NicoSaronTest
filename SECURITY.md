# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=%23%23%20Vulnerability%20Details%0A%0A**Type:**%20[e.g.,%20XSS,%20SQL%20Injection]%0A**Severity:**%20[Low/Medium/High/Critical]%0A%0A%23%23%20Steps%20to%20Reproduce%0A%0A1.%20...%0A%0A%23%23%20Impact%0A%0A[Describe%20the%20potential%20impact%20of%20this%20vulnerability]).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
