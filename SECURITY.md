# Security Policy

## Supported Versions

The table below outlines the security support status for recent versions of this project:

| Version | Supported | Notes                                    |
| ------- | --------- | ---------------------------------------- |
| v1.x    | ✅ Yes    | Active development and security updates. |
| < v1.0  | ❌ No     | End of life. Please upgrade to v1.x.     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the issue via email using our structured template:
   - **Structured Link:** [Report Vulnerability via Email](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%3A%0A%0A-%20Vulnerability%20Type%3A%20%5BType%5D%0A-%20Severity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A-%20Description%3A%20%5BDescription%5D%0A-%20Steps%20to%20Reproduce%3A%20%5BSteps%5D%0A-%20Impact%3A%20%5BImpact%5D)

   If the link above does not work with your mail client, please email [security@example.com](mailto:security@example.com) with the following copy-paste template:

   ```text
   Subject: Security Vulnerability Report

   - Vulnerability Type: [Type]
   - Severity: [Low/Medium/High/Critical]
   - Description: [Description]
   - Steps to Reproduce: [Steps]
   - Impact: [Impact]
   ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
