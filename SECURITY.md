# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | ✅ Yes             |
| 1.1.x   | ❌ No              |
| < 1.1   | ❌ No              |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [Click here to report a vulnerability via email](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type:%20[Vulnerability%20Type]%0A%0ASeverity:%20[Low/Medium/High/Critical]%0A%0ADescription:%0A[Provide%20a%20detailed%20description]%0A%0ASteps%20to%20Reproduce:%0A[Step%201]%0A[Step%202]%0A%0AImpact:%0A[What%20is%20the%20potential%20impact?])
3. Alternatively, email your findings to [security@example.com](mailto:security@example.com) with the following details:
   - Vulnerability Type
   - Severity
   - Description
   - Steps to reproduce
   - Potential impact

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
