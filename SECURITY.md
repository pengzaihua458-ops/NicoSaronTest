# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BType%20of%20Vulnerability%5D&body=Thank%20you%20for%20helping%20keep%20our%20project%20secure%21%20Please%20provide%20the%20details%20below.%0A%0A---%0A%0A%23%23%20Severity%0A%5BWhat%20is%20the%20estimated%20severity%20-%20Low%2FMedium%2FHigh%2FCritical%5D%0A%0A%23%23%20Description%0A%5BPlease%20describe%20the%20vulnerability%20and%20its%20nature%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A%5BPlease%20provide%20clear%2C%20step-by-step%20instructions%5D%0A%0A%23%23%20Impact%0A%5BWhat%20could%20happen%20if%20this%20vulnerability%20is%20exploited%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
