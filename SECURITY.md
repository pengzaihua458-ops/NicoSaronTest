# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BInsert%20Short%20Description%5D&body=Thank%20you%20for%20helping%20keep%20our%20project%20secure%21%20Please%20provide%20the%20details%20of%20your%20findings%20below.%0A%0A---%0A%0A%2A%2A1.%20Vulnerability%20Type%2A%2A%0A%5Be.g.%20XSS%2C%20RCE%2C%20SQL%20Injection%2C%20Information%20Disclosure%5D%0A%0A%2A%2A2.%20Severity%2A%2A%0A%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A%2A%2A3.%20Description%2A%2A%0A%5BDescribe%20the%20vulnerability%20and%20its%20potential%20impact%5D%0A%0A%2A%2A4.%20Steps%20to%20Reproduce%2A%2A%0A1.%20%0A2.%20%0A3.%20%0A%0A%2A%2A5.%20Impact%2A%2A%0A%5BWhat%20could%20an%20attacker%20achieve%20by%20exploiting%20this%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
