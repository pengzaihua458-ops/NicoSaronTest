# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BShort%20Description%5D&body=Thank%20you%20for%20helping%20keep%20our%20project%20secure%21%20Please%20fill%20out%20the%20details%20below.%0A%0A---%0A%0A%23%23%20Vulnerability%20Type%0A%5Be.g.%20XSS%2C%20RCE%2C%20Auth%20Bypass%2C%20etc.%5D%0A%0A%23%23%20Severity%0A%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A%23%23%20Description%0A%5BPlease%20provide%20a%20clear%20and%20concise%20description%20of%20the%20vulnerability%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A3.%20%5BStep%203%5D%0A%0A%23%23%20Impact%0A%5BWhat%20could%20an%20attacker%20do%20by%20exploiting%20this%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
