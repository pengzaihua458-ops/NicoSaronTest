## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via email using our [structured mailto link](mailto:security@example.com?subject=%5BSecurity%20Report%5D%20Vulnerability%20in%20Repository&body=**Vulnerability%20Description**%3A%0A%0A**Steps%20to%20Reproduce**%3A%0A1.%20%0A2.%20%0A%0A**Impact**%3A%0A%0A**Suggested%20Fix**%3A%0A).
3. Alternatively, send an email to [security@example.com](mailto:security@example.com) using the fallback template below.
