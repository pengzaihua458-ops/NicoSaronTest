# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅ Supported       |
| < 0.1   | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. Please follow these steps to report a vulnerability:

1. **Do not** open a public issue.
2. Email findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=%23%23%23%20Description%0A%0A%23%23%23%20Steps%20to%20Reproduce%0A%0A%23%23%23%20Potential%20Impact).
3. Use the template below for your report.

### Reporting Template

```markdown
### Description
A clear description of the vulnerability.

### Steps to Reproduce
1. ...

### Potential Impact
What could an attacker do?
```

## What to Expect

- **Acknowledgement**: We will respond within 2 business days.
- **Updates**: We will provide weekly updates until resolved.
- **Credit**: We will give you credit if requested once fixed.

Thank you for helping keep this project secure!
