# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report via email: [Email Security Team](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Please%20provide%20as%20much%20detail%20as%20possible.%0A%0A-%20Vulnerability%20Type%3A%20%5BType%5D%0A-%20Severity%3A%20%5BHigh%2FMedium%2FLow%5D%0A-%20Affected%20Component%20%2F%20File%3A%20%5BComponent%5D%0A-%20Description%3A%20%5BDescription%5D%0A-%20Steps%20to%20Reproduce%3A%20%5BSteps%5D%0A-%20Suggested%20Fix%20%2F%20Remediation%3A%20%5BFix%5D)
3. Alternatively, send your findings to `security@example.com` with a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
