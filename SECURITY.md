# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=%23%23%23%20Vulnerability%20Details%0A-%20Type%3A%20%0A-%20Severity%3A%20%0A%0A%23%23%23%20Description%0A%5BDescribe%20the%20vulnerability%20here%5D%0A%0A%23%23%23%20Steps%20to%20Reproduce%0A1.%20%0A2.%20%0A%0A%23%23%23%20Impact%0A%5BDescribe%20the%20potential%20impact%5D).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
