# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Hi%2C%0A%0AI%20have%20found%20a%20security%20vulnerability%20in%20this%20project.%0A%0A%23%23%20Description%0A%5BDescribe%20the%20vulnerability%5D%0A%0A%23%23%20Steps%20to%20Reproduce%0A1.%0A2.%0A3.%0A%0A%23%23%20Impact%0A%5BDescribe%20the%20impact%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce (the link above includes a template for your convenience).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
