## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0A%0ASteps%20to%20reproduce%3A%0A%0A%0AImpact%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Copy-Paste Fallback Template

If the mailto link above does not work with your mail client, please use the following template to report your vulnerability:

```text
To: security@example.com
Subject: Vulnerability Report

Description:
[Please provide a detailed description of the vulnerability here]

Steps to reproduce:
1.
2.
3.

Impact:
[Describe the potential impact if this vulnerability is exploited]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
