# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report%3A%20%5BBrief%20Description%5D&body=%23%23%23%20Vulnerability%20Details%0A-%20**Type%3A**%20%5Be.g.%2C%20XSS%2C%20SQLi%2C%20Auth%20Bypass%5D%0A-%20**Severity%3A**%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0A%23%23%23%20Description%0A%5BDetailed%20description%20of%20the%20vulnerability%5D%0A%0A%23%23%23%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A3.%20%5BStep%203%5D%0A%0A%23%23%23%20Impact%0A%5BWhat%20is%20the%20potential%20impact%20of%20this%20vulnerability%3F%5D).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
