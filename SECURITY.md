# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send a report via email using our [Structured Security Email Template](mailto:security@example.com?subject=%5BSecurity%20Vulnerability%20Report%5D%20%5BComponent%2FModule%5D&body=Summary%3A%0A-%20Describe%20the%20vulnerability%20briefly.%0A%0AImpact%3A%0A-%20What%20can%20an%20attacker%20achieve%3F%0A%0ASteps%20to%20reproduce%3A%0A1.%0A2.%0A3.%0A%0AProposed%20Remediation%20%28optional%29%3A%0A-).
3. Alternatively, copy and paste the fallback template below into your email to `security@example.com`:

```markdown
Subject: [Security Vulnerability Report] [Component/Module]

Summary:

- Describe the vulnerability briefly.

Impact:

- What can an attacker achieve?

Steps to reproduce:

1.
2.
3.

## Proposed Remediation (optional):
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
