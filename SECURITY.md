# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via email to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Dear%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20security%20vulnerability%20in%20this%20project.%0A%0A-%20Vulnerability%20Type%3A%20%5Be.g.%20XSS%2C%20RCE%5D%0A-%20Vulnerability%20Location%3A%20%5Bfile%2C%20endpoint%2C%20or%20dependency%5D%0A-%20Description%3A%20%5Bbrief%20description%5D%0A-%20Steps%20to%20Reproduce%3A%0A%20%201.%20%0A%20%202.%20%0A%20%203.%20%0A-%20Impact%3A%20%5Bpotential%20impact%5D%0A%0AThank%20you!).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Email Template Fallback

If the link above does not open your mail client, please copy and paste the template below into an email to **security@example.com** with the subject **Security Vulnerability Report**:

```text
Subject: Security Vulnerability Report

Dear Security Team,

I would like to report a security vulnerability in this project.

- Vulnerability Type: [e.g. XSS, RCE]
- Vulnerability Location: [file, endpoint, or dependency]
- Description: [brief description]
- Steps to Reproduce:
  1.
  2.
  3.
- Impact: [potential impact]

Thank you!
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
