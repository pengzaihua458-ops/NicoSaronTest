## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send your report via [email to security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Title%3A%20%0A%0ASeverity%3A%20%0A%0AComponent%3A%20%0A%0ADescription%3A%20%0A%0ASteps%20to%20Reproduce%3A%20%0A%0AImpact%3A%20).
3. Alternatively, copy and fill out the vulnerability template below.

### Vulnerability Report Template

```text
Title:
Severity: [Low/Medium/High/Critical]
Component:
Description:
Steps to Reproduce:
Impact:
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
