# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Please%20provide%20the%20following%20details%20in%20your%20report%3A%0A%0A-%20Type%20of%20vulnerability%3A%0A-%20Estimated%20severity%20(Low%2FMedium%2FHigh%2FCritical)%3A%0A-%20Description%3A%0A-%20Steps%20to%20reproduce%3A%0A-%20Impact%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce. For convenience, please include the following fields in your report:
   - **Type of vulnerability**
   - **Estimated severity** (Low/Medium/High/Critical)
   - **Description**
   - **Steps to reproduce**
   - **Impact**

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
