# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Supported       |
| < 1.0.0 | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [Click here to report via email](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type:%0A-%20[e.g.,%20XSS,%20SQL%20Injection]%0A%0ASeverity:%0A-%20[Critical/High/Medium/Low]%0A%0ADescription:%0A-%20[Detailed%20description]%0A%0ASteps%20to%20Reproduce:%0A1.%0A2.%0A3.%0A%0AImpact:%0A-%20[Potential%20consequences]) or email your findings to [security@example.com](mailto:security@example.com).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
