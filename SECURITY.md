# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Supported       |
| < 1.0   | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%0A%0ASeverity%3A%0A%0ADescription%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Vulnerability Report Template

To help us process your report quickly, please include the following information:

- **Type**: (e.g. Buffer Overflow, XSS, etc.)
- **Severity**: (Critical, High, Medium, Low)
- **Description**: A clear and concise description of the vulnerability.
- **Steps to Reproduce**: Steps to reproduce the behavior.
- **Impact**: What could happen if this vulnerability is exploited?

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
