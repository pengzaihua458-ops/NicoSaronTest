# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%3A%0A).
3. Alternatively, if your mail client does not support mailto links, copy and use the template below:

```text
Subject: [SECURITY REPORT] Vulnerability Report

Description:
<Provide a detailed description of the vulnerability>

Steps to Reproduce:
1. <Step 1>
2. <Step 2>

Impact:
<Describe the potential impact>
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
