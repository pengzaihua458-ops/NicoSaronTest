# Security Policy

[![Security Policy](https://img.shields.io/badge/Security-Policy-brightgreen.svg)](SECURITY.md)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us immediately.

### Preferred Method: Email

Please send your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=Description:%0A%0AReproduction%20Steps:%0A%0AImpact:).

### Reporting Template

If your email client does not support pre-filled links, please use the following template in your report:

```markdown
### Description
A clear and concise description of what the vulnerability is.

### Reproduction Steps
1. [First Step]
2. [Second Step]
3. [etc.]

### Impact
What is the potential impact of this vulnerability?
```

## Our Commitment

1. **Do not** open a public issue for security vulnerabilities.
2. We will acknowledge receipt of your report within 48 hours.
3. We will provide an estimated timeline for a fix and keep you updated on our progress.

Thank you for helping keep this project secure!
