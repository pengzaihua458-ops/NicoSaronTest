# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅                |
| < 1.0   | ❌                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%0A%5BType%20of%20vulnerability%5D%0A%0ASeverity%3A%0A%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0ADescription%3A%0A%5BDescription%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%0A2.%0A3.%0A%0AImpact%3A%0A%5BWhat%20could%20happen%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Detailed reporting instructions:
- **Type**: The type of vulnerability (e.g., XSS, SQLi, etc.)
- **Severity**: Your assessment of the severity (Low/Medium/High/Critical)
- **Description**: A clear and concise description of the vulnerability
- **Steps to Reproduce**: Detailed steps to reproduce the issue
- **Impact**: What is the potential impact if exploited

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
