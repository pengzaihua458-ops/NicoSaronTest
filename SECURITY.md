# Security Policy

## Supported Versions

Below are the versions of this project currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| Main    | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using this structured reporting template:
   [Report Vulnerability via Email](mailto:security@example.com?subject=Vulnerability%20Report&body=Description:%20%5BEnter%20vulnerability%20description%5D%0A%0ASteps%20to%20reproduce:%20%5BEnter%20steps%20to%20reproduce%5D%0A%0AImpact:%20%5BEnter%20potential%20impact%5D).
3. If the link does not work or you prefer a manual email, please copy and paste the template below to `security@example.com`.

### Fallback Template

```text
Subject: Vulnerability Report

Description:
[Enter vulnerability description]

Steps to reproduce:
[Enter steps to reproduce]

Impact:
[Enter potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
