# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. [Email your findings to security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BInsert%20Short%20Title%20Here%5D&body=Thank%20you%20for%20helping%20keep%20our%20project%20secure%21%20Please%20fill%20out%20the%20details%20below%3A%0A%0A-%20**Vulnerability%20Type%3A**%20%5Be.g.%20XSS%2C%20RCE%2C%20etc.%5D%0A-%20**Severity%3A**%20%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A-%20**Description%3A**%20%5BProvide%20a%20detailed%20description%5D%0A-%20**Steps%20to%20Reproduce%3A**%0A%20%201.%20%5BStep%201%5D%0A%20%202.%20%5BStep%202%5D%0A-%20**Impact%3A**%20%5BWhat%20can%20an%20attacker%20do%3F%5D) using our pre-filled template.
3. Alternatively, you can copy the markdown template below and email it manually to **security@example.com**.

### Vulnerability Report Template

```markdown
- **Vulnerability Type:** [e.g. XSS, RCE, etc.]
- **Severity:** [Low / Medium / High / Critical]
- **Description:** [Provide a detailed description of the findings]
- **Steps to Reproduce:**
  1. [Step 1]
  2. [Step 2]
- **Impact:** [What is the potential impact or what can an attacker do?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
