# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5Be.g.%2C%20Remote%20Code%20Execution%2C%20SQL%20Injection%2C%20XSS%5D%0A%0ASeverity%3A%20%5BLow/Medium/High/Critical%5D%0A%0ADescription%3A%20%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A3.%20%0A%0AImpact%3A%20%5BWhat%20is%20the%20impact%20of%20this%20vulnerability%3F%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Vulnerability Report Template

If your mail client does not support pre-filled links, please copy and paste the template below into your email:

```text
Type: [e.g., Remote Code Execution, SQL Injection, XSS]

Severity: [Low/Medium/High/Critical]

Description: [Provide a detailed description of the vulnerability]

Steps to Reproduce:
1.
2.
3.

Impact: [What is the impact of this vulnerability?]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
