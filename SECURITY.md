# Security Policy

## Supported Versions

Below are the versions of the project currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BBrief%20Description%5D&body=Hello%20Security%20Team%2C%0A%0AI%20have%20discovered%20a%20security%20vulnerability%20in%20the%20repository.%0A%0A%23%23%23%20%F0%9F%93%9D%20Description%0A%5BPlease%20provide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0A%23%23%23%20%F0%9F%94%8E%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0A%23%23%23%20%F0%9F%8E%AF%20Impact%0A%5BWhat%20is%20the%20potential%20impact%20or%20severity%20of%20this%20issue%3F%5D%0A%0AThank%20you%20for%20your%20help%20in%20keeping%20this%20project%20secure%21).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Copy-Paste Reporting Template

If your mail client does not support structured links, you can copy the template below and send it to **security@example.com**:

```markdown
Subject: 🛡️ Vulnerability Report: [Brief Description]

Hello Security Team,

I have discovered a security vulnerability in the repository.

### 📝 Description

[Please provide a detailed description of the vulnerability]

### 🔎 Steps to Reproduce

1. [Step 1]
2. [Step 2]

### 🎯 Impact

[What is the potential impact or severity of this issue?]

Thank you for your help in keeping this project secure!
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
