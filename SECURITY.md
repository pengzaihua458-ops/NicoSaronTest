# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us:

1. **Do not** open a public issue.
2. Report via the [GitHub Security Advisory channel](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new).
3. Fallback: Email [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
