# Security Policy

## Supported Versions

The table below outlines the security support status for recent versions of this project:

| Version | Supported        |
| ------- | ---------------- |
| v1.0.x  | ✅ Supported     |
| < v1.0  | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Description%3A%20%5BEnter%20vulnerability%20description%5D%0A%0ASteps%20to%20reproduce%3A%20%5BEnter%20reproduction%20steps%5D%0A%0AImpact%3A%20%5BEnter%20estimated%20security%20impact%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

Alternatively, you can copy and paste the fallback template below into your email client:

```text
Subject: 🛡️ Vulnerability Report

Description:
[Provide a clear and concise description of the security issue]

Steps to Reproduce:
1. [First Step]
2. [Second Step]
3. [Third Step]

Expected Behavior:
[What should happen securely]

Actual Behavior:
[What actually happens]

Estimated Security Impact:
[What an attacker could accomplish if they exploit this issue]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
