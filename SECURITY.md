# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| v1.x    | ✅ Yes    |
| < v1.0  | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Type%3A%20%5BType%20of%20vulnerability%20e.g.%20Buffer%20Overflow%2C%20XSS%2C%20etc.%5D%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0ADescription%3A%20%5BDescription%20of%20the%20vulnerability%5D%0ASteps%20to%20reproduce%3A%20%5BHow%20to%20reproduce%5D%0AImpact%3A%20%5BWhat%20is%20the%20potential%20impact%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
