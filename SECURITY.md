# Security Policy

## Supported Versions

We currently support the following versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Supported       |
| < 1.0.0 | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [Structured Security Report Template](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5BXSS%2FSQLi%2Fetc%5D%0ASeverity%3A%20%5BCritical%2FHigh%2FMedium%2FLow%5D%0A%0ADescription%3A%0A%3Cdescription%20of%20the%20vulnerability%3E%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%3A%0A%3Cwhat%20could%20happen%20if%20exploited%3E). Alternatively, you can send an email to `security@example.com`.
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
