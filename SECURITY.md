# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Type%3A%20%5Be.g.%2C%20SQL%20Injection%2C%20XSS%2C%20RCE%5D%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0ADescription%3A%20%5BWhat%20is%20the%20vulnerability%3F%5D%0ASteps%20to%20reproduce%3A%20%5BHow%20can%20we%20see%20this%20in%20action%3F%5D%0AImpact%3A%20%5BWhat%20could%20happen%20if%20this%20is%20exploited%3F%5D).
3. Provide a detailed description of the vulnerability (Type, Severity, Description, Steps to Reproduce, Impact).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
