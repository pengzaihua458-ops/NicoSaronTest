## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us using one of the methods below:

### Email Report

Click here to send an email: [Report Security Vulnerability](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A)

### Report Template

If you cannot use the link above, please copy and fill out the template below when emailing [security@example.com](mailto:security@example.com):

```text
Subject: Security Vulnerability Report

Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:
1.
2.
3.

Impact:
[Describe the potential impact of this issue]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
