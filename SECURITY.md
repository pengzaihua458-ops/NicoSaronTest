# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1.  **Do not** open a public issue.
2.  Report the vulnerability via [GitHub Security Advisories](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new). This is our preferred method of receiving reports.
3.  Alternatively, you can email your findings using our [structured report template](mailto:security@example.com?subject=Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AExpected%20Behavior%3A%0A%0AActual%20Behavior%3A%0A%0AImpact%3A).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
