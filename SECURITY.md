# Security Policy

![Security Policy](https://img.shields.io/badge/Security-Policy-informational)

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=###%20Description%0A%0A%5BDescribe%20the%20vulnerability%20here%5D%0A%0A###%20Steps%20to%20Reproduce%0A%0A1.%20%0A2.%20%0A3.%20%0A%0A###%20Impact%0A%0A%5BDescribe%20the%20potential%20impact%20here%5D).
3. Alternatively, you can use the [Reporting Template](#reporting-template) below.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!

## Reporting Template

If your email client does not support the pre-filled link above, please use the following template for your report:

```markdown
### Description
[Describe the vulnerability in detail]

### Steps to Reproduce
1. [Step 1]
2. [Step 2]
3. [Step 3]

### Impact
[Describe the potential impact of this vulnerability]
```
