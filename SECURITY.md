## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send your findings via email to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20Reproduce%3A%0A%0AImpact%3A).
3. Alternatively, you can copy and paste the template below into your email:

```text
Subject: Security Vulnerability Report

Description:
[Provide details about the vulnerability]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]

Impact:
[Describe potential security impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
