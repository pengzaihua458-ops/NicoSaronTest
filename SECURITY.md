## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us via GitHub Security Advisories or by following the steps below.

### Reporting Channel

1. **Do not** open a public issue.
2. Report via [GitHub Security Advisories](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new).
3. Alternatively, email your findings to [security@example.com](<mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=**Vulnerability%20Type:**%0A**Severity:**%0A**Affected%20Component(s):**%0A**Description:**%0A**Steps%20to%20Reproduce:**%0A**Proof%20of%20Concept:**%0A**Impact:**%0A**Suggested%20Mitigation:**>).

### Response Timeline

We will acknowledge receipt of your report within **48 hours** and provide an initial assessment within **7 business days**.

Thank you for helping keep this project secure!
