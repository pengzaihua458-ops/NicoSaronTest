## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%20of%20vulnerability%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. If mailto is not supported, copy and submit using the fallback template below:

```text
Vulnerability Report
-------------------
Description:
Steps to reproduce:
Impact:
```

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
