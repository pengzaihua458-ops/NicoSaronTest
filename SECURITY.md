# Security Policy

## Supported Versions

We actively support and secure the following versions of our software:

| Version | Supported |
| ------- | --------- |
| v1.x    | ✅ Yes    |
| < v1.0  | ❌ No     |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to our security team. You can use this [direct email link](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report%3A%20%5BType%20of%20Vulnerability%5D&body=Hello%20Security%20Team%2C%0A%0AI%20would%20like%20to%20report%20a%20potential%20security%20vulnerability.%20Below%20are%20the%20details%3A%0A%0A-%20**Vulnerability%20Type%3A**%20%5Bvulnerability%20type%20or%20category%5D%0A-%20**Affected%20Version%2FComponent%3A**%20%5Bversion%2Ffile%2Fendpoint%5D%0A-%20**Severity%3A**%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0A###%20Description%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0A###%20Steps%20to%20Reproduce%0A1.%20%5BFirst%20step%5D%0A2.%20%5BSecond%20step%5D%0A%0A###%20Impact%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D%0A%0AThank%20you%20for%20helping%20us%20keep%20our%20users%20safe!).
3. Alternatively, copy and paste the following template and email it to **security@example.com**:

```markdown

I would like to report a potential security vulnerability. Below are the details:

- **Vulnerability Type:** [vulnerability type or category]
- **Affected Version/Component:** [version/file/endpoint]

### Description

[Provide a detailed description of the vulnerability]

1. [First step]
2. [Second step]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
