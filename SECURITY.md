## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Description%3A%0A%0AImpact%3A%0A%0ASteps%20to%20Reproduce%3A).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

If you prefer copy-pasting, please use the following template for your email:

```text
Subject: Security Vulnerability Report

Description:
[Provide a clear and concise description of the vulnerability]

Impact:
[Describe the potential security impact]

Steps to Reproduce:
1. [First Step]
2. [Second Step]
3. [Third Step]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
