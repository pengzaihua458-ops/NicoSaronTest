# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings directly using our [Pre-filled Security Email Template](mailto:security@example.com?subject=%5BSECURITY%5D%20Vulnerability%20Report&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A1.%20%0A%0AImpact%3A%0A).
3. If the mail link does not open your email client, send an email to **security@example.com** using the template below:

```text
Subject: [SECURITY] Vulnerability Report

Description:
[Provide a detailed description of the vulnerability]

Steps to Reproduce:
1. [First Step]
2. [Second Step]

Impact:
[Describe the potential impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
