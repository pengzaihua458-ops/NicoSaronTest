# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report the vulnerability via the [GitHub Security Advisory](https://github.com/pengzaihua458-ops/NicoSaronTest/security/advisories/new) (Recommended).
3. Alternatively, email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=###%20Description%0A%0A[Provide%20a%20detailed%20description%20of%20the%20vulnerability]%0A%0A###%20Steps%20to%20Reproduce%0A%0A[Include%20clear%20steps%20to%20reproduce%20the%20issue]%0A%0A###%20Impact%0A%0A[Describe%20the%20potential%20impact%20of%20this%20vulnerability]).

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
