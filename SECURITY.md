## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using this [structured security report link](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20In%20Repository&body=Title%3A%20%0ADescription%3A%20%0ASteps%20to%20reproduce%3A%20%0AImpact%3A%20).
3. Alternatively, copy and paste the report template below into an email to `security@example.com`.

### Security Report Template

```text
Title: [Short title describing the vulnerability]
Description: [Detailed description of the issue]
Steps to reproduce:
1.
2.
3.
Impact: [Potential security impact if exploited]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
