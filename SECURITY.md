## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Please%20describe%20the%20vulnerability%20and%20steps%20to%20reproduce.).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

### Report Template

When submitting a security report, please include the following information:

- **Description**: A clear description of the vulnerability.
- **Impact**: What could an attacker achieve by exploiting this issue?
- **Steps to Reproduce**: Detailed steps or a proof-of-concept script.
- **Affected Components**: Specific files, endpoints, or configurations involved.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
