# Security Policy

## Supported Versions

Below are the currently supported versions of this project and their security patch status:

| Version | Supported | Notes |
|---------|-----------|-------|
| 1.0.x   | ✅ Yes     | Active support |
| < 1.0.0 | ❌ No      | End of life |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Vulnerability%20Report&body=Type%20of%20Vulnerability%3A%0A%5BType%5D%0A%0ASeverity%3A%0A%5BSeverity%5D%0A%0ADescription%3A%0A%5BDescription%20of%20the%20issue%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%0A2.%20%0A%0AImpact%3A%0A%5BImpact%20statement%5D).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
