# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](<mailto:security@example.com?subject=Security%20Vulnerability%20Report&body=Dear%20Security%20Team%2C%0A%0AI%20am%20writing%20to%20report%20a%20potential%20security%20vulnerability%20I%20discovered%20in%20this%20project.%0A%0AVulnerability%20Type%3A%20%5Be.g.%2C%20XSS%2C%20SQLi%2C%20etc.%5D%0ASeverity%3A%20%5BLow%2FMedium%2FHigh%2FCritical%5D%0A%0ADescription%3A%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0ASteps%20to%20Reproduce%3A%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A%0AImpact%3A%0A%5BDescribe%20the%20potential%20impact%20of%20this%20vulnerability%5D%0A%0AProposed%20Fix%20(optional)%3A%0A%5BDescribe%20how%20you%20think%20this%20can%20be%20fixed%5D%0A%0AThank%20you%2C%0A%5BYour%20Name%5D>).
3. Provide a detailed description of the vulnerability, including steps to reproduce.
