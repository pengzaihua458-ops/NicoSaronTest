# Security Policy

## Supported Versions

| Version | Supported        |
| ------- | ---------------- |
| 1.0.x   | ✅ Supported     |
| < 1.0.0 | ❌ Not Supported |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via our [Vulnerability Reporting Template](mailto:security@example.com?subject=Vulnerability%20Report&body=Vulnerability%20Details%3A%0A-%20Type%3A%20%0A-%20Severity%3A%20%0A%0ADescription%3A%20%0A%0ASteps%20to%20Reproduce%3A%20%0A%0AImpact%3A%20) or email [security@example.com](mailto:security@example.com).
3. Provide a detailed description of the vulnerability, including steps to reproduce.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
