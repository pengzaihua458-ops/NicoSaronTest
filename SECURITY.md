## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings using our [vulnerability report template](mailto:security@example.com?subject=%5BSECURITY%20REPORT%5D%20Vulnerability%20in%20Repository&body=Description%3A%0A%0ASteps%20to%20reproduce%3A%0A%0AImpact%3A).
3. If mailto links are not supported, you can send an email to `security@example.com` using the following template:

```text
Subject: [SECURITY REPORT] Vulnerability in Repository

Description:
[Detailed description of the vulnerability]

Steps to reproduce:
1.
2.

Impact:
[Describe potential security impact]
```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
