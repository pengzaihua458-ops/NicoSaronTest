# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Email your findings to [security@example.com](mailto:security@example.com?subject=Vulnerability%20Report&body=###%20Description%0A%0A###%20Steps%20to%20Reproduce%0A%0A###%20Expected%20Behavior%0A%0A###%20Actual%20Behavior%0A%0A###%20Impact).
3. Provide a detailed description of the vulnerability using the template provided in the email.

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
