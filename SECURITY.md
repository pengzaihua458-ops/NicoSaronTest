# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Report your findings via email to [security@example.com](mailto:security@example.com?subject=%F0%9F%9B%A1%EF%B8%8F%20Security%20Vulnerability%20Report&body=Please%20provide%20as%20much%20detail%20as%20possible%20to%20help%20us%20understand%20and%20resolve%20the%20issue.%0A%0A---%0A%0A%23%23%201.%20Vulnerability%20Type%0A%5BType%20of%20vulnerability%2C%20e.g.%2C%20XSS%2C%20SQL%20Injection%2C%20etc.%5D%0A%0A%23%23%202.%20Severity%0A%5BLow%20%2F%20Medium%20%2F%20High%20%2F%20Critical%5D%0A%0A%23%23%203.%20Description%0A%5BProvide%20a%20detailed%20description%20of%20the%20vulnerability%5D%0A%0A%23%23%204.%20Steps%20to%20Reproduce%0A1.%20%5BStep%201%5D%0A2.%20%5BStep%202%5D%0A3.%20%5BStep%203%5D%0A%0A%23%23%205.%20Impact%0A%5BWhat%20could%20an%20attacker%20do%20by%20exploiting%20this%3F%5D) (this link will open your email client with a pre-filled, structured template).

   _If the link doesn't work with your mail client, please email **security@example.com** using the following copy-paste template:_

   ```markdown
   Subject: 🛡️ Security Vulnerability Report

   ## 1. Vulnerability Type

   [Type of vulnerability, e.g., XSS, SQL Injection, etc.]

   ## 2. Severity

   [Low / Medium / High / Critical]

   ## 3. Description

   [Provide a detailed description of the vulnerability]

   ## 4. Steps to Reproduce

   1. [Step 1]
   2. [Step 2]
   3. [Step 3]

   ## 5. Impact

   [What could an attacker do by exploiting this?]
   ```

We will acknowledge receipt of your report and provide an estimated timeline for a fix. Thank you for helping keep this project secure!
